# R14 预登记：Boundary-State-Aware Motion Diffusion

基准 e0b7100，R13 权重/数据/采样/Native及正式路径冻结。
独立代码 src/dunhuang/research/boundary_state_r14。先 P0/P1；没有证据不启动新去噪器训练。

## P0：冻结责任定位与必要界

保留 R13 四个已曝光适配持出 Train 组全部案例，包含0/3失败，不重采样人口。
读取两个模型完整50步 raw x0，分别计算左右位置、D1/D2、角速度、相对位移错误，
以及按真实 [60,90) 回接后的足端 Root平移/Root旋转/局部姿态对称分解。
中间步只是冻结状态读出，不能当完整反事实采样；分解不是因果归因。

必要不可修复性只对 Native joint_jerk_mps3_max 建立：
Native FP32 FK 的四帧第三差分模板若完全落在编辑域外，且其值超过原环境门限，
则任何只编辑 [60,90) 的候选都不能通过该全局最大值条目。
核对与原 Native 数值相同，保存帧模板、关节、限值与文件身份。
没有证据时为UNKNOWN，不标可行。地面、足滑人口、全局P95等均保持UNKNOWN。
本证据只排除固定编辑权限，不证明扩大范围或全局生成无解，不放宽验收标准。

在八个既有 Train-fit 的 policy250 缓存状态上，用冻结 final400 模型检查目标冲突：
raw已知Root、未知来源姿态、实际回接FK足端、两端Peak Jerk。
计算原选定504万参数空间的梯度Gram与最小范数凸组合；
两个固定参数RMS（1e-5、5e-5）做有限步验证，逐次恢复原参数并核对digest。
这不是网络训练，不保存新模型；目标含配对未知区真值，仅是Train容量/冲突诊断，
不能作为推理方向。缓存是旧自身策略状态，不称当前on-policy。Torch FK须与Native对齐。

## P1：同参数状态表示诊断

两端真实 Root/SO3 与位置D1/D2来自52:60及90:98，绝不读取未知区构造条件。
24D状态：相对位移、两端速度/加速度、SO3相对转向、两端角速度，另附观测掩码。
Root/支撑未知不零填为真值；本轮无接触或人工语义真值，支撑状态保持UNKNOWN。

A0：完整原始16帧Root/24姿态及Mask；A1追加位移；A2再加两端速度和加速度；
A3再加转向/角速度；A4为A3等维同角色跨音乐组置乱。
原始输入使用左Root坐标，同时保留重力方向；不删除姿态倾斜物理信息。
所有头同维度、同岭回归系数0.01，不做超参扫描。

显式状态是原始观察的确定性变换，不包含Shannon意义上的额外信息。
要检验的是计算捷径/正则化偏置，不做“预测自己构造的状态标签”的循环验证。
拟合标签是真实配对未知Root轨迹相对线性端点参考的残差，以及相对SO3线性插值的
6D旋转残差；仅拟合/评分读取未知真值。推理参考只从已知观察和已拟合头构造，
不直接写入最终Root，不重新包装旧Hermite输出修复。

只在R13原1399窗/36音乐组内按seed14041的组SHA排序，前8组作头持出，剩28组拟合。
它们可能已被R13/基础模型训练，不宣称独立基础模型泛化。
旧四个monitor与Val不参与头拟合/选择。归一化和难度阈值仅由28组计算。
按位移/转向/加速度的Train三分位报告难度分层；不使用接触代理冒充支撑真值。
置乱保留同角色总体人口并跨组，禁止跨拟合/持出取供体。

P1准入：相对A0的组均Root误差至少降低2%，至少6/8组改善；
比A4至少降低2%，方向误差不恶化0.01rad。按A1→A2→A3固定低复杂度顺序选首个合格，
不选最好分数。头是解析诊断拟合，单独计数5；不是0个可学习参数，也不是新去噪训练。

## P2 追加预登记（P1读出后、P2执行前）

P1按固定顺序选择A2，A3不择优替换。现在登记冻结去噪器输入条件容量诊断。
从8个头持出音乐组各按seed140410和来源哈希固定选一窗，不按P1误差选窗。
头虽持出，R13模型可能训练过这些组；不称独立泛化。

先运行8条冻结R13基线50步，取t519/19的自身轨迹状态；
不重新训练头、不改变模型权重。在同一x_t、音乐、噪声和硬观察上，
比较无引导、A0原观察头参考、A2状态头参考、跨组置乱A2状态参考。
参考只由真实8+8观察和既定头构造；目标仅Root位置和Root朝向。
在x_t未知区Root/Root六维旋转共270坐标上施加一次固定RMS0.02梯度条件，
不替换最终Root、不修改真硬观察、不使用未知真值选方向或步长。
对每个方向以eps0.001做中心差分，数值导数相对误差5%或绝对1e-4内。

保存每个raw x0回接后的完整Native/FK。
容量准入要求16个状态逐一Root误差改善、来源姿态不退化1e-5rad，
左右每个接缝Root步长、转角、足端最大步长和Peak Jerk均不退化1e-5相对值；
A2相比A0和置乱在至少6/8组更好，组均相对Root收益至少2%，数值梯度检查通过。
这只是单状态容量，若通过仍须另登记完整自身策略引导采样后才能准入人口训练。
未通过则停止P3；不追加扫描步长，不改成输出Root修复。
