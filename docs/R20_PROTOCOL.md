# R20：双端视野、时刻支持与实际采样时序预登记

基准9c2100ca455bd2a23204640e22f4bb1794663b81。独立temporal_r20包。
正式路径、R13–R19、原Scaler/FK/Native、CFG=2、裁剪[-1,1]冻结。
不增加新生成骨干、RootNet或新的可训练状态头参数；本轮先结构、后目标。
不是CondMDI完整模型复现，不替换音乐预训练权重或伪造新Jukebox资产。

## 数据/任务/人口

R19 N2末态是结构两组共同来源。继承完整225帧同录制/校准音频、音乐所有权、
151D动作和观察Mask。仅Fit case0/1训练；Fit2/3作本轮适配未用、但历史曝光的DEV。
DEV不得选择结构、权重、缓存准入或迭代次数，不叫盲测/基础模型未见泛化。
每case是一段225帧，不把多个种子、干预或重复采样当独立来源。
仍是可靠真实双端的INBETWEEN：首尾各8帧及固定上身关键姿态，112代理阶段。
不等于没有未来Root的FREE，更不等于ChangE音乐重新演绎或整曲。
C4未知不参与真值损失。

## 第一阶段：结构S0/S1，目标不变

S0：当前两个150视图、共享225潜变量、原self状态头、均值融合。
S1：一次225-token双向EDGE前向，直接看左右两端；取消双视图融合。
动作观察和Mask仍直接进入动作投影，音乐由真实225所有权缓存拼接，
绝不对音频/音乐特征插值或把150帧特征拉长。
225 null_cond_embed从原1×150×512沿时间线性插值、align_corners=True，
固定不训练，新增38400冻结参数；其余冻结参数逐值相同。
默认RoPE/Identity绝对位置前提显式检查；不兼容后端拒绝扩长。
selected motion5040279与原状态头97728参数完全一致。
S1状态头为同参数全局self，主干自身也完整读取双端，不把协调只押在U头上。
分别记录移除状态头时的单前向右端影响，检验主干直接视野。
长度适配改变音乐/注意力视野和null条件，是结构包，不能把所有差异归因单一操作。

两组从同一N2参数来源开始、重新初始化AdamW，各240更新、lr1e-4。
目标保持R19 N2：balanced未知+.1 raw观察+原四项固定物理权重。
相同两来源、噪声、时刻、硬软顺序与更新预算，仅结构不同。
每8步遍历两case×t999/519/119/19，每case/t30次，硬软各15。
预算是更新数匹配，不是FLOPs匹配；记录前向次数、token处理量代理、墙时与峰值显存。

双端干预：correct、left_wrong、right_wrong、left_absent、right_absent、both_absent。
错配使用另一个Train来源的同侧完整Root/旋转块，保留本源共享原点解释；
它是参考兼容性干预，不称艺术上错误。移除端同时移除其观察/硬保留Mask。
音乐、噪声、时长、另一端、内部关键姿态不变。
始终用原正确条件的未知中间Mask计分，不能因移除端改变分母或只计硬保留端。
q在50步网格记录正确条件，四旧时刻另做全部左右干预。
结构实际生成：两组×Train2×六控制×一个固定种子，共24次及独立重采样。
评价raw边缘、共同中间误差、远侧响应、Root朝向/边界速度、各接缝及Native。
结构选择只用Train：S1两case均需q中间误差≤S0的1.1倍，
正确条件优于四种单侧错配/移除；raw边缘Root、实际Root/姿态误差、
Jerk P95均不高于S0的1.1倍，活动度至少S0的.8。
全部通过选S1，否则保留S0；这是探索性继续条件，不是结构最终资格。

## 第二阶段：统一共同起点，时间/时序/缓存递进

A0/A1/A2（可选A3）均从选定结构最后状态开始、重置优化器，各追加240更新。
A0：四旧时刻，原N2目标，控制额外训练。
A1：同N2目标，时刻支持扩展。
A2：A1加校准全身配对速度/加速度残差。
A3：条件性执行；A2相同目标/初始/时刻/噪声账本，半数输入改为自身采样x_t。
没有把结构变化和时序目标当一个对照。

时刻分布明确为 .5 U{0..999} + .5 U{50步推理网格}：
前一半按10个100宽区间固定分层；后一半每50项随机无放回循环。
A1/A2/A3时刻完全相同，A3只替换grid槽的输入状态，故缓存占比恰为.5。
这是全区间支持的有限采样，不声称240更新遍历每个t，更不是Min-SNR。

新全身项在米、30Hz下匹配D1/D2真实FK残差，Huber(delta=1)，
速度尺度3m/s，加速度30m/s²。Root/下肢/躯干/上肢四组分别按有效模板/坐标均值，
再等权平均。速度排除原足端四点；Root在原局部seam监督区域不重复记权。
加速度足端此前未覆盖，保留。作用于触及未知区的模板，已知全段不冒充编辑域。
不把运动压到零；匹配目标的快速运动同样被保护。原目标并非物理合格教师。

新权重只在共同起点、固定Train2×8时刻×硬软32状态校准，
lambda=.1/[2 max(1,median_motion_ratio,median_head_ratio)]，每项≤.05，
参考范数分母下界1e-12；原N2物理权重不改。
静态预算不是GradNorm，不用DEV/生成结果拟合权重。

A2/A3均在更新0/120生成4条225全局缓存（两来源×硬软），总8条/组，
A2只作计算匹配与诊断、训练仍用q；A3 grid槽使用当前最近刷新缓存。
缓存完整保存50个实际x_t，并绑定来源/数据/音乐/时钟/Root/Mask、
Scaler、采样器、权重快照与代码。0刷新用共同结构末态；120刷新用各组自身119-post。
独立进程加载这些快照重建缓存，禁止优化器。
这些x_t不严格服从q，原配对目标只是登记的恢复目标，不称唯一艺术真值。
缓存是逆扩散状态，不是前段生成历史。

A2结束后，在两Train用一个固定种子做实际50步采样。
若两case四旧时刻q误差≤共同起点1.25倍，且至少一case的实际t19/q t19误差比≥2，
才运行A3。DEV/完整Native不作这项有限研究训练的前置门。

## 分层追踪与受控融合读出

Frozen R19 N2在原种子复现两条R19轨迹，必须逐值一致，证明仪表未改变数学路径。
另在相同种子比较均值与五次平滑分割权重融合，各两条。
仅冻结诊断，不自动更改训练/后续采样默认均值；6D特征插值不称SO(3)融合。
正式结构和时序组不改CFG、不删除裁剪、不改变epsilon。

代表case0/seed0/correct逐50时刻记录：
unc/cond、CFG裁剪前、裁剪后、两局部窗、融合/联合、硬保留后FK，
饱和/实际裁剪比例、逐关节比例、旋转有效性、全局/内部/观察边缘/融合位置Jerk，
以及峰值末端祖先链局部旋转变化。无效旋转单列，不将无效FK指标当有效物理证据。
四时刻保存代表阶段张量；其他时刻保留标量，不保存所有神经元大张量。
S1的75/150只是与旧融合位置对齐的测量区，实际没有融合算子。

跟踪动作直投影、观察残差、状态残差、合并输入、第一个/最后Decoder、输出的RMS与非有限比例。
更新索引0/119/239保存pre/post，记录实际更新和各层参数/激活梯度；
最后Decoder参数冻结而激活梯度可非零，不误称断路。
独立加载状态重算梯度/delta/前后读出；不声称完整重新优化重跑训练。

## 固定最终评价

S0/S1/A0/A1/A2及A3若准入，在Train2+DEV2、两个固定种子做正确条件实际采样，
共40或48次；另有结构24、A2准入2、冻结融合4及缓存采样成本，分别计数。
结构Train seed0与最终对应执行是重复读出，不当独立样本。
DEV只在全部组/决定固定后执行，不参与反复调参。
逐项报告balanced实际误差、内部/观察/旧融合位置Jerk、原Native、
速度/角速度分布、姿态与阶段、运动范围和足端指标。
