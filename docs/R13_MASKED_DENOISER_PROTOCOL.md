# R13 预登记：真实 Mask-Conditioned Motion Denoiser

基准 04f817b；R12 权重、代码、报告封存。代码只放
src/dunhuang/research/masked_denoiser，不改正式路径和原 Native 标准。

## 新机制

Motion Token 直接由 [where(mask, observation, x_t), observation*mask, mask]
构成。输入线性核拆分以保持空 Mask 初始化与原 EDGE 逐位一致；
观测列零初始化，噪声列继承原权重。该输入没有 RMS=0.1 残差上限。
训练完整输入投影、首个 Decoder block 和最终输出层；Rotary 参数、音乐编码器及其他
动作层均冻结。共享动作条件进入 CFG 的两条支路，CFG=2，只丢音乐；
不是继续训练 R12 B3，也不增加新的输出姿态写入器。原 Dropout 关闭，
初始化/选定参数/冻结参数和实际采样账本都记录。

真实 AIST++ 151D 配对目标和时钟保持原版。没有接触真值、人工事件真值或伪造 Root。

## P0：教师与官方兼容性

固定 R12 缓存中前四个 Train-fit 窗，四个实际 B0 x_t 时刻。
正确已知边界的一步归一化梯度（RMS=0.1）、错配梯度、随机方向及 B0 对照；
未知目标 NaN 毒化必须不改变梯度。它不是精确 argmin，不宣称可部署的教师。
四例完整50步教师采样，与同种子的冻结B0缓存比；独立复验 FK/原 Native、
两侧接缝、活动度及未知姿态。教师必须所有原 Native 通过，来源姿态不比 B0
恶化0.01rad，逐接缝足端最大步长不恶化0.01m，才可作为动作教师。
否则保留诊断，不做未合格教师蒸馏。新架构的真实配对小样本训练不依赖教师通过。

DanceFusion 固定官方代码与 CondMDI 代码提交，检查 90帧/151D/音乐/前后Token、
数据模块、官方checkpoint包元数据及归一化。只核验公开权重包的小范围目录和 args；
不把不完整官方代码或 EDGE Normalizer 冒充可复现独立基线，不加载外国权重到 EDGE。

## P1：四窗可过拟合性

四个固定 Train-fit 窗×四个固定 q 噪声时刻，batch4，240更新，lr=1e-4；
只用最终权重，不扫描学习率/强度/层数。继承 R12 原有 raw x0 损失与权重，
区别是动作去噪路径真正可训练。正确/单侧错配/移除不改变真实硬约束。

准入：四例中至少三例的已知 Root RMSE、已知 SO3角误差及未知区重建误差，
相对初始化的平均值均下降至少25%；正确条件同时分别胜过左错配与右错配至少3/4。
这只证明训练集内机制，不是泛化或整曲准入。未通过则停止人口训练。

另做50步完整rollout：四例正确；前两例追加移除/左错配/右错配，硬边界固定；
四个固定 correct-driven 状态上保留六种条件读出，正确raw x0保留全部50步。
四例冻结 R12 B3 同种子对照仅为历史基线，训练人口/参数量不同，不能当公平架构消融。

## P2/P3：仅通过 P1 后

从原 EDGE 重新初始化，1399窗/36音乐组拟合人口、4个持出Train音乐组监测。
400更新batch2。前100步真实 q；第100/250更新各用自身快照采样8个拟合窗，
随后50% q +50%最近自身快照缓存。保存选定权重、快照digest、x_t与训练账本；
缓存称滞后的自身策略快照数据，不称每一步完全on-policy。
最终权重固定，完整采样与冻结R12 B3对照；不根据监测和曝光Val重选。

## 评价与隔离

分别报告59→60及89→90的Root位移、Root转角、足端最大步长，
各自Peak Jerk与max-joint Jerk离散时间积分（单位m/s²），raw已知状态误差、
来源姿态、活动度、实际两侧条件响应及原 Native。保护区逐位相同。
绝对 Native 与局部相对收益分开；原输入的 Native 状态也保留。

所有新模型 operational_qualified=false。未取得可信单窗来源及原物理资格，
不接入ChangE阶段条件，不跑三首整曲；不启动RootNet/SQP/PFG。
全程代码先推 GitHub、服务器精确SHA同步、tmux、独立新进程零优化器重放，
五类权重/输入/状态/代码/数据来源哈希封存。仅清理本轮SSH与传输辅助物。


## 追加的只读诊断（不改变训练、准入或权重选择）

最终权重在四个固定真实 rollout 状态与同时间步的新 q 状态上重算：
新 q 种子固定为 seed+80000+case*4+state_index。报告已知 Root/旋转的 pre-clip
饱和比例、已知状态误差，并验证自身轨迹的预测逐位重现。单独核查末步
raw x0→硬覆盖→反归一化→Native 的两端 Root 链。该诊断只用于解释结果，
不追加调参。原输入和局部教师的单状态 FK/Native 审计作为独立附录，
保留原 P0 回执，不以新附录覆盖旧结果。
