# R69：冻结来源的重定时基线与独立质量比较

六组：Uniform＋G1、原E1-W＋G1、BeatDP改编＋G1、RhythmDTW改编＋G1、R67 Single64／Multi64选择＋G1。当前系统称强基线，不命名为Ours。

固定原12个来源—音乐位置、8个来源区间，240帧Core、48帧连接、528帧完整片段；来源身份、顺序、邻接、音乐区间与数值门均固定。历史三首音乐已开发曝光，本轮仅是回顾性比较。没有新增来源泛化或新音乐测试主张；新音乐可另行冻结登记，不能从文件名推断未曝光。

R67原候选、实际编码分数、首个登记最高分选择及原连接直接复用，逐一核原封存SHA、q、实际来源旋转和完整片段。Uniform复用R68的相同执行。复用成本与历史162条候选的编码／几何计算分开；历史未记录的耗时保持UNKNOWN，不能记为0。不是重新运行SDMR。

新DP与DTW均是有限节点域的受速率约束分段线性改编，不是完整文献复现。DP以现有上身速度峰代理为节点，以自动拍点为吸引目标；DTW思路以来源上身角速度及音频onset曲线全支持z归一后比较。它们的内部目标不是独立音乐质量评价，速度峰也不是人工动作重音。两组具有不同候选域，六组是端到端基线比较，不是同候选、同计算量的评分器归因。

每节点保留精确匀速位置与附近15帧内所有整数位置；最多8个内部节点，局部dt/ds∈[0.75,1.33]。保留匀速路径用于避免仅整数离散化排除边界合法执行，这一选择在读取新实验结果前冻结。DTW不是先做无约束路径再裁剪。无事件、常量特征或无法出解的位置保留，不替换、不回退成E1-W。每个新执行都从来源实际重采样，再重新求解原48帧G1，检查完整Core没有被连接器改写。

先生成具名观看和匿名评价包，完整17.6秒音频同步；可切换8秒Core模式作诊断，原速来源独立播放。匿名页面不包含方法、分数、来源身份、mask或管理员映射；映射和随机种子仅存服务器admin目录。具名页用于开发反馈，不将已看过具名结果的人自动认定为独立评价者。

独立评价采用音乐协调、自然性、转场时机、连续性、丰富度五维1–5分，允许同分、UNSURE、UNRATED及部分完成。普通观看不需要填写身份；只有科研记录导出需要审核编号与曝光声明，格式验证不等于身份核验。有效独立比较需要额外管理员核验与至少两名不同真实评价者，不能合成评价记录。缺记录时仍完成动态、覆盖及计算成本实验，音乐与艺术质量保持NOT_EVALUABLE。

机器指标只作来源支持、几何执行、FK／SO(3)动态和成本诊断。D3高低不能单独判自然性，优化目标高不能单独判卡点。无Native24、世界Root／接触证据则不宣称物理合格；不升级Planner、不训练新模型、不扩到整曲。

直接相关机制参考：[ChoreoGraph](https://arxiv.org/html/2207.07386)、[Dance to the Beat](https://link.springer.com/article/10.1007/s41095-018-0115-y)。本实验只借鉴受限重定时及节奏对齐思想，不复现其完整特征、动态图或视频处理系统。
