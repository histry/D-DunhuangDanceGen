# E1-W：固定原语与门限的时间映射可行域实验

本轮只改变四节点映射的音乐中心求解，保持原499个UID、Core、E0/E1锚点、25帧来源窗口、Scaler、49个音乐槽位与0.75–1.33变速门限。生产pipeline、旧Planner和time_map V1不修改。新求解器是显式导入的数学worker，独立研究编排位于research/primitive_warp。

配置冻结于configs/primitive_warp_v1.json，来源绑定已成功的data_event_v3_04回执及证据SHA。T0=E0+旧策略，T1=E1+旧策略，T2=E0+可行域，T3=E1+可行域。四组不进行参数选择、训练、Native筛选或新生成；旧G2不合格，新Data V3也不自动赋予A2候选或训练资格。

## 可行域与时刻选择

源[a,b)、槽[A,B)、源中心c、半径12；L=c-a-12，R=b-c-12。要求L,R>0，且25帧窗口全部在真实观测范围内。零长度外段仍拒绝，不合并端点、不移动真峰。

合法tau是以下闭区间的交集，再取整数帧：
[A+12+0.75L, A+12+1.33L]；
[B-12-1.33R, B-12-0.75R]；
[A+12, B-13]。
全部边界用百分之一帧整数计算，精确实施3/4与133/100，区分空连续域和没有整数时刻；未放宽浮点容差。

在合法整数中，依次最小化：
1. 距本槽检测节拍的距离；
2. 距原线性投影时刻的位移；
3. 时刻本身（更早优先）。
没有槽内节拍时只用后两项，节拍距离标为null。拍点不一定有资格；拍点不可行时可以选择最近合法非拍点，不能称为已匹配音乐重音或真实音乐语义。

    tmux new-session -d -s ddg-e1w 'bash scripts/run_primitive_warp.sh outputs/primitive_warp_01 outputs/primitive_warp_01_receipt > outputs/primitive_warp_01.log 2>&1'

每个新算法的事件—槽位组合均独立穷举所有整数tau，验证完整合法集合及选择目标的全局最优性（每进程48,902组），同时使用原V1时间算子验证阶段顺序和逆映射。T0/T1布尔矩阵必须与旧Data V3精确一致；T2/T3不许丢失各自旧策略合法对。

报告每组合法对、事件/来源覆盖、空槽、拍点距离、线性位移、相同合法对的tick变化、阶段逆序与反演误差；区分T0-T1净计数差、真正T0独占集合以及T3恢复了哪些集合。数学可行性不是艺术或生成质量。

主运行和复验的maps.npz、certificates.json及科学读数逐项一致后才导出聚合汇总。launcher退出后另运行：

    python scripts/export_primitive_warp.py --out outputs/primitive_warp_01 --receipt outputs/primitive_warp_01_receipt --seal
