# R67: frozen SDMR over a shared legal Warp domain

This isolated research package preserves Fixed48, E1-W, R41 weights and the
original G1 numerical screen. No neural training, new Planner search or learned
proposal generation runs here. A candidate is `(source event, legal Warp)`.
Temporal legality, local connection feasibility and artistic utility are
separate qualifications.

First audit existing kinematic event types on R66's actual paired recordings.
Report every registered lag from −15 to15 frames, for identical event supports
under correct, noncircular shifted and wrong-song clocks. Do not select a best
test-sample lag, tune event weights, or convert an exploratory lag curve into a
new reward. Hold/turn representative centers are not semantic completion or
human accents. Pose extrema remain unavailable without a registered detector.
Mapped source peaks and re-detected output peaks are compared as detector
consistency, not event truth. Retiming changes speed by the clock derivative,
so changed maxima are not automatically an implementation error.

For ChangE, reuse twelve R66-B positions with eight distinct source intervals
and three exposed music tracks. Seal all candidate banks before encoding:
baseline first, then original R53 K-best cost order, at most16 scanned paths,
q de-duplication at1e-9, no padding or score-guided replacements. K1/4/8/16 are
prefixes of exactly the same table. Every candidate executes SO(3) resampling,
recomputes274D observations/masks and uses the same frozen R41 checkpoint.
Time/duration channels stay masked; R59 music is already normalized and is
never normalized twice.

All ChangE candidates also replace their corresponding Core in the frozen
528-frame pair. Recompute G1 against the original neighbor and48-frame budget
and apply the original numerical screen. Store actual pair/Bridge arrays and
boundary jets; cache hits and actual solves are separate. Do not inherit older
Bridge qualification. Raw ranking and ranking among G1-screened states are
saved separately, and an empty feasible set requires abstention. The viewer
shows raw ranking with connection status and does not authorize routing.

The fixed-budget paired diagnostic uses twelve existing AIST Val recordings
from six historically exposed music groups, newly defined center240 crops.
Both untouched and controlled noncircular perturbations remain registered.
Neutral synthetic clock nodes are experimental design points, never motion
events. Freeze the bank before selecting an injected existing map. Verify both
injection and recovery directions, candidate membership and composition truth.
Measure the exact full original DAG oracle, bank/prefix oracle and selection
regret separately; never add oracle paths to the bank. Double SO(3) resampling
error is measured separately from known clock error.

The main2×2 is K1/K16 versus Single64/Multi64. K4/8 are dose diagnostics.
Single64 pools64 nonoverlapping bins. Multi64 pools32 fine,16 mid,16 overlapping
coarse windows with coverage correction and fixed .5/.25/.25 scale weights.
UniformReadout64 repeats nonoverlapping mid windows to control the aggregation
layout; repeated bins are not independent information. Every method/control/K
uses the maximum-bank and actual/zero/swap common valid token support, with
time holes preserved, real end bins, post-pool L2 normalization, and explicit
empty/near-zero failures. Random, deformation, energy and original diagonal
readouts are separate baselines. Maximum internal score is not an outcome.

Selection error and negative-error interaction are aggregated within raw
recording, then equally across six music groups. K1 has only one fixed-event
Warp, so its output clock error cannot depend on readout: the interaction here
reduces to the K16 selector difference, not general synergy evidence. P2
negative results still permit this one preregistered2×2; do not then expand K,
fit weights on Val or upgrade Planner. Target-domain quality and artistic
oracle recall remain NOT_EVALUABLE without independent labels.

Run published code in tmux, first `phase_audit`, then `main`, deliver the actual
watching package, then `controls`. Independently replay each mode into a fresh
directory with `verify --replay-mode MODE --out PATH`. Preserve manifests,
model fingerprints, complete failures, logs and exit status. Clean only this
run's temporary SSH helpers. No full-song or Native24 qualification follows.

ChoreoGraph is a direct neighboring method: its music-conditioned re-timing
and dynamic graph overlap this problem, so Warp-before-scoring is not claimed
as a new contribution. [Primary paper](https://arxiv.org/html/2207.07386).
Soft-DTW smooths the minimum over alignment costs; it is not itself a legal
E1-W execution map. [Primary paper](https://proceedings.mlr.press/v70/cuturi17a.html).
