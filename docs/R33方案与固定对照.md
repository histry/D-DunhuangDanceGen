# R33：单一 Lodge 主干、参考路由与来源相对动态对照

基准 main7a207915。正式生成及历史基线不变；研究代码独立于 production。
一个冻结 Lodge Local/Canonical ActionIO，保存 R31 通用参考和 R32 ChangE 参考两个小分支，以 catalog domain 整窗显式路由。AIST change_replay 是训练对照，不能冒称通用分支已经迁移。零初始化上下文残差与来源残差同时读取原始 hidden；当前 context 未训练，不宣称双端控制成功。mask、左右时间、observed/generated/planned 与来源条件独立；未知 Root/C4 不提供真值。音乐 CFG 的双分支均使用相同来源条件。

Train-only 实际访问状态校准 D1/D2 的误差尺度及任务梯度。单位30Hz，分部位和有效差分模板均衡；D3 仅评价。8次真实有限 AdamW 更新决定是否准入。通过后 Extra/Dyn 各600步，从同一个 R32 权重出发，复用其来源完全均衡的600行 schedule。两组仅动态系数不同；AdamW/lr/teacher/300步状态刷新/音乐丢弃完全一致。NoRef、冻结通用分支、IO/主干不变。

额外来源在生成前按 catalog recording_uid 锁定 female_lotus_sequence 与 female_meditation_sequence，每条选时长至少96帧且 event_uid 字典序首项；不按性能挑事件，不使用它们校准权重。它们来自历史曝光 catalog，仅是本轮适配录制隔离观察，不是独立文化盲测。原 inventory 的音乐拍点取0:96；实际 Core 为64:160。训练前修正为64:160并平移到局部0:96。原 data 保留，held_compilation_v2 单独编译并新进程重放；source IDs 不变。第一轮新编译因 data 被误写为 preflight 目录而在读入阶段失败，零训练/生成，保留失败回执。

完整采样固定 Frozen/Extra/Dyn 三组、相同音乐/噪声与原50步采样器。ChangE 两条训练来源和两条额外录制，均做 correct/wrong_clock/swapped/NoRef。另在AIST Train/holdout 实际采样验证通用路由及 NoRef 与R31完全一致。共30次 sampler、156条轨迹，每个新进程重放重复同一人口，禁止优化器。

评价前固定研究门槛：每条训练来源的SO(3)/腕部向量误差不超过 Frozen 的1.1倍，活动和幅度为其0.9–1.1倍；琵琶 paired body D2/D3 及 Core body Jerk 均低于 Frozen；飞天D2/Jerk不超过1.1倍。报告 Extra 与 Dyn 的直接差异，不按额外来源选胜者。Hann96残差6Hz以上功率为描述性诊断，不是新的训练项或艺术质量指标。Root/world/body Jerk、两侧 Core 边缘与外部区域分别报告；Root/C4 UNKNOWN，22关节不能伪装为24关节 Native 合格。

R33不训练phi、不训练context、不新增PCGrad、不跑整曲；单种子研究不作统计泛化或敦煌文化真实性结论。三首整曲仍待单事件来源、时间及完整物理资格建立之后。
