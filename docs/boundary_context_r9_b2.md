# R9-B2：随机掩码／边界状态 Adapter 固定训练合同

依据R9-B1局部提案0/48与真实DataV3预检Train1833/Val273，执行条件已成立。科学主线R9-S/B0/B1正在执行时不改变其服务器checkout；本合同与代码先发布，待主运行完整退出后独立tmux执行。

单一预训练EDGE保持8层512D和151D输出。小Adapter输入真实已知Root/旋转、观测掩码、只在连续观测中计算的一阶二阶差分，以及两维帧位置；结合冻结音乐编码512D，经128D单层Transformer与零初始化512D残差输出加入原cond_encoder。参数单独优化；不会修改主干或默认EventMusicAdapter。源接触和手指未知数据不参与本训练；AIST官方实际24关节来源可用，接触代理始终不监督。

数据使用新的DataV3角色，严格关联raw/audio SHA、起点、音频偏移和真实已缓存Jukebox。不是用旧A2局部特征资格替代生成目标。已观测上下文和被遮蔽目标的147个Root/旋转通道已通过冻结Normalizer；不声称窗口所有其他帧也均满足支持域，不裁剪真实数据。窗口以编辑区外的原始第0帧XZ为坐标原点（该帧在实际补全任务中受保护、可观测，但不额外送入局部8+8帧Adapter），保留高度。Train/Val音乐组48/6，官方角色不变，Test读取0；这些仍是已有开发曝光人口，不称全新盲测。

随机遮蔽区起点60..66、终点84..90，已知两端各8帧；25%保留全部关节，其余随机保留80%关节，Root位置始终观测。所有训练掩码都在预检支持的[52,98)内。条件编码完全屏蔽未知值，测试验证不能通过数值或差分泄漏未知真值。真实音乐保持配对。

固定种子20261114、batch2、AdamW lr1e-4、300步、梯度范数1，训练t均匀覆盖0..999的完整反向噪声支持，最后checkpoint唯一，不用Val选择权重或训练轮数。损失为遮蔽147D的标准化MSE，再加两端实际Root速度/加速度与SO(3) body角速度/角加速度差：Root D1 .01、D2 .0001，angular D1 .001、D2 .00001；速度按30FPS、加速度按900缩放。梯度测试检查有限性和非监督区梯度为零。主干逐参数requires_grad=false并校验更新前后摘要。

训练后固定32个Val窗、timesteps100/500/900/999，一次评价zero/observed/removed/wrong四个条件控制，共享噪声；wrong在批内交换上下文，不交换音乐。所有控制使用同一最后权重，不据此再训练或选最佳。新进程加载冻结checkpoint重新计算全部读数，优化器步数0，验证数值一致。

实际生成使用按种子和音乐组轮转固定选出的8个Val窗，比较零Adapter与新Adapter，同一50步hard-context DDIM及噪声。仅将中间[60,90)回接到该真实原始窗口；编辑区外逐位保护，保存未经回接的原模型数组和回接动作。上下文、原目标及新动作都按原Native报告，不过滤原本Native失败的目标。16次真实短窗生成及16次新进程重放，128数组与Native结果逐位／逐项一致才完成复验。

本训练解决一般配对音乐下的局部双端条件补全，不等于学习了敦煌文化风格。没有用ChangE未知Root/contact或伪造的配对音乐作真值。B3来源联合和三首整曲仍要分别满足来源与完整物理门；本合同不会自动授予正式生成资格。

应用域反事实：另在R8原四例实际生成上下文上比较zero/learned，两组同噪声。zero六类数组必须与旧R8无来源Inpainting逐位相同；两组再新进程完整重放，新增16次短窗执行。这里不启用ChangE来源引导，仅检验学习式双端条件从AIST迁移到原生成上下文，不能据此声称B3来源联合已经完成。
