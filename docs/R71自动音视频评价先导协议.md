# R71: frozen R69 audio-video automated judge pilot

This is a research evaluator, separate from production generation and R69 baselines.
No motion model is trained. Registered population: 60 baseline-versus-candidate
comparisons, 56 eligible, four exclusions retained. These are historically exposed
development examples, not new music or unseen-source generalization.

Before evaluation freeze cases 0, 4, 7, E1W versus Single64, both A/B orders.
Render actual 528-frame rotations at 30 FPS, common camera, appearance and scale;
reuse the frozen 17.6-second paired audio. First deliver these six input videos.
Judge videos contain no method names; local viewing documentation may identify them.

Use official Qwen2.5-Omni-7B-AWQ and official low-VRAM code, with text output,
talker disabled, SDPA, 1 FPS visual sampling, fixed 71071 seed, greedy decoding.
Record actual modality shapes, raw responses including schema failures, model/code
hashes, software versions, elapsed time and measured CUDA memory. Do not infer
30 FPS sensitivity from sparse video input. No model or media is uploaded to APIs.

Technical admission requires both modalities processed, no OOM, valid input
clocks and saved raw outputs. Preserve failures; do not switch examples or prompts
until a desirable answer appears. In a new process replay the first case, explicitly
reporting disagreements rather than discarding them.

Then run the same visuals with muted input, non-circular +500 ms audio shift
(zero padding), and another registered case's music, both A/B orders: 18 controls.
Full 112 order-swapped eligible comparisons are conditional on technical admission;
do not treat that number as independent statistical samples. Report order consistency
and audio-control responses by source, without automatic quality winner selection.

All judgments are automated, human_reviewed=false. Human agreement, independent
artistic quality and Native24 remain NOT_EVALUABLE. MotionCritic input is not admitted
without a validated Root/SMPL conversion. No zero-Root score is reported. R69's full
30 FPS numerical diagnostics remain separate from the judge's perceptual opinions.

Official references: https://github.com/QwenLM/Qwen2.5-Omni and its author-published
ModelScope Qwen/Qwen2.5-Omni-7B-AWQ mirror. Official memory estimates are not this
machine's measured peak. Weight files and third-party model source remain ignored assets.

Deployment correction: use the official utils' torchvision reader. The Decord 0.6.0 wheel declares cp36 ABI metadata and fails Python3.10 pip admission, despite decoding successfully. Remove it only from the isolated R71 environment; do not alter its metadata.
