## 三种任务不得混同
FREE：只有源upper8关键姿态和音乐/事件时钟，没有未来Root或外部完整真值动作输入。
INBETWEEN：真实首尾8+8动作条件，硬/软执行明确；硬观察边缘8/217必须独立评价。
PROGRESSIVE：仅使用先前已生成且哈希绑定的75帧前缀，Root/姿态历史固定，
未来Root/完整动作不得取测试真值。源关键姿态在前缀区与历史冲突时以历史优先。
所有任务C4均未观测；prefix接触预测不是支撑真值。
真实外侧动作不作为FREE的必需验收输入。225原点唯一，不能对第二视图重新定心。

## P2 新合同与模型
全局潜变量[1,225,151]；局部模型只接收两个[150,151]/[150,4800]视图，
统一噪声、Root原点、音乐与事件进度。原R13权重和音乐编码器全部冻结。

A_numeric：只有数值共享，重叠预测平均；这是旧思想的基线，不宣称新贡献。
B_cross：在R13动作输入投影后，query取512D动作Token，
key/value取对侧窗口的Root/Pose(147D)、观测Mask(147D)、全局钟/事件相位(4D)。
经298→64→64状态编码和64D注意力、全局时间距离偏置，投回512D条件。
零初始化输出投影，初始与A逐值相同；每步双向交换对侧非重叠内容，而非只平均75帧。
C_self：同参数、同初始化、同预算，改为从本窗口状态读取，控制额外参数与训练贡献。
两种学习模型均97728参数，不更新旧504万参数，不加RootNet/输出姿态写入器。
removed/reversed时间反事实只改变共享状态内容，主音乐/源观察/全局位置不变。

各学习模型固定240更新、AdamW lr0.0003、grad clip1、每步一对。
不做Val选模/早停/学习率扫描，只保存最后权重。
随机Train任务含free、inbetween、真实过去前缀的progressive teacher forcing及额外稀疏关节观察；边界硬软各半，
事件交界随机80..144；不永远训练60:90。
每步从统一225真值q_sample噪声，再切视图；不同视图相同帧具有相同噪声。
三种真实任务的语义不因训练随机Mask而互换。

Loss = recon +0.1 boundary +0.1 world_FK +0.05 context：
recon只用147个Root/旋转通道；boundary含raw已观测Root/姿态、全局Root D1/D2；
FK匹配真实配对足端位置/速度，不让所有脚静止，不用预测接触作标签；
context每4步加correct vs时间反转邻域的recon排序margin0.01。
Torch FK逐个225源与Native核对≤1e-5m；全局算损失，不重新按150求导或切边界。

评价所有4个Eval组，A/B/C均FREE/INBETWEEN/PROGRESSIVE实际50步采样，
同任务同seed；PROGRESSIVE共用A的FREE生成前缀，绝非真实未来片段。
每个采样t519/19保存同状态correct/reversed/removed读出，加载最后权重独立重放，
重放拟合/优化0，不把同状态CF当完整反事实采样。
用全局Root、SO3、足端、全局最坏Jerk及8/75/150/217等位置分别审核。
B优于A与同预算C、正确邻域优于反事实，才支持额外跨窗口机制收益。
预登记探索门：至少3/4组在FREE与INBETWEEN均获得Root/足端/Jerk至少2%改善，
并在同状态recon上优于removed/reversed；每项分开报告，不以均值掩盖坏例。
即便通过，也不是完整Native或敦煌舞风格资格；无新整曲，无大规模训练。
