# 局部表征可辨识性：R1诊断与有条件R2

冻结基线为01c0515。历史A/B/C、D/E/F、128D编码器、默认Planner/EDGE/Native不改。复用event_id_02与clock_root_04已核验并独立重放的Train/Val缓存，核验输入SHA、完整源Sidecar、角色及关联身份；Test不读取。

## R1-A：分层线性可访问性

local_information_audit.py在两个模态分别比较原始50D/74D、TCN、偶帧采样、[1,2,1]/4抗混叠后采样、原Transformer。统一到实际帧2..116的30Hz网格：15Hz特征只在实测支持内插值，不复制末帧、不环绕。这样TCN与其直接下采样不因评价都只取偶帧而变成同一个输入。

每个模态、每级使用同1419参数线性探针，Train-only闭式ridge拟合，正则0.01；不训练编码器或增加神经模块。11输出包含3个连续数值代理、3个峰邻域代理、5个事件类型代理。音乐连续目标直接重建音频控制量，只是可访问性上界；动作连续目标为固定骨架FK速度。类型/峰值标签来自独立数值检测，不是人工事件对应。Root平移不在74D中，不能把Root差异当作压缩损失。

增加±1/2/3帧响应，所有表示使用相同的目标与真实支持交集帧5..113，不填充。报告MSE、数值峰argmax误差、峰邻域AUC、类型代理AUC/F1；线性探针失败不能证明信息不可恢复。

## R1-B：内容代价、几何与固定路径

token_geometry_audit.py固定E头、NULL代价、0.5秒带宽、掩码、候选。比较全144D、仅128D Token、仅16D描述、内容置零、仅Token打乱和全部内容打乱；后两者保持时间/掩码，逐源确定性置换。置零仍保留真实事件时刻、数量，不能称完全无信号。另用Train-only z-score与正则白化作只读对照，统计变换单独记录，投影参数不增加。

对同一全内容硬路径锁定后重评分，分别保存内容、时间、固定NULL常数。只有这条锁定路径上的分解可加；重新求解的分数差是干预描述，不能当可加因果贡献。另用纯时间几何代价0.2*距离/带宽构造固定模板，只在这条不看内容的模板上汇聚内容余弦；模板不是逐事件真值。

原始128D/144D及投影144D统计均值方向、范数、协方差谱、有效秩、Hubness。几何统计按完整源事件身份去重，避免把同一音频的重复引用误当Hubness；原始128D同帧去重、144D保留类型/身体部位区别。Hubness最多4096节点的固定种子子集。重复录制只作同音乐/同编舞/同来源时钟一致性代理，同一音频的重复不是独立声音证据。

来源窗正负的矩阵分布、AUC和Recall均只是来源关联任务，不把正确来源窗内每条Token边标成正事件。原150窗候选作为已曝光诊断人口单列。主要条件挑战只取同歌曲、同编舞、相隔至少120帧的错时段，并匹配两侧事件数量、相对时间W1≤0.15秒、4格时间直方图L1≤0.25、音频与动作能量log比≤log1.25、起音密度差≤0.25次/秒。规则提前固定，全部失败条件留证。不足时不放宽。

## R1-C：五类损失的梯度

loss_gradient_audit.py使用原Train采样表的0/100/200/300行，记录检索、合成移位、合成路径、合成NULL、弱对应对两侧144D投影的梯度及5×5余弦。NULL冻结，零梯度明确标为不可定义。每个非零梯度只在独立模型副本上作0.0005一步虚拟SGD干预，保存自身损失、来源排名、路径间隔、固定时间模板上的内容间隔变化；原权重不变。

这是注册的虚拟参数干预，不是持久训练；重放时也会重算这些干预。因此优化器调用0与虚拟副本更新数分别报告，不能把前者解释成没有任何参数扰动。

## R2：只在严格人口足够时执行

每个角色至少30查询/15录制，Train至少3个关联组、Val至少2个组；任一不足则R2不启动，记录数据不足，不用旧150窗替代严格挑战。通过时四组相同144D投影、固定NULL、相同候选/Train采样、400步/batch12/学习率0.0005：暖启动路径检索、暖启动条件内容、同参数冷启动条件内容、暖启动打乱内容关联。只替换主来源判别目标，不叠加新网络或TCC。

条件目标是固定时间模板上平均内容余弦的多正例对比，不是全路径分数减置零分数。模板独立于内容，NULL/时钟不参与学习。允许不同舞者的可信同时间演绎承载正例。冷启动也复制相同固定NULL。总41473参数、可训练41472参数，不扩容。固定最后一步，不在Val选模型或加步数。补验原96条合成身份/NULL及五偏移任务以暴露退化。

无论结果如何，已曝光Val仅两个已知关联组、人工事件真值0，不能获得新来源泛化或语义定位资格。继续Shadow，不接正式生成。

## 工程与复核

先推送GitHub，服务器ff-only拉取，再tmux运行scripts/run_local_identifiability.sh。预检、完整回归、依赖补跑、审计、有条件训练和新进程逐数组/指标重放均留回执。完整矩阵、模型与来源清单留服务器，仅白名单脱敏聚合JSON发布。本轮SSH认证仅内存，不落盘辅助文件。

## 一手依据及边界

[Temporal Cycle-Consistency Learning，CVPR 2019](https://openaccess.thecvf.com/content_CVPR_2019/html/Dwibedi_Temporal_Cycle-Consistency_Learning_CVPR_2019_paper.html)讨论无逐帧标签的时间一致性；[GTA，CVPR 2021](https://openaccess.thecvf.com/content/CVPR2021/html/Hadji_Representation_Learning_via_Global_Temporal_Alignment_and_Cycle-Consistency_CVPR_2021_paper.html)将全局序列对齐与表示学习联系。本轮只借鉴问题拆分与路径监督视角，未复现两篇网络，未将音乐—动作循环当语义标签。

已核对[Google Research原作者TCC代码与README](https://github.com/google-research/google-research/tree/master/tcc)，其明确提醒位置编码可能产生计数式平凡解。用户方案引用的kln-cmu-mscv/TCC不能仅凭名称认定作者官方实现。绝对/相对位置线索可以使循环恢复成功，不能独立证明跨模态语义对应。本轮不引入TCC、PFG、Drifting或新的求解器。
