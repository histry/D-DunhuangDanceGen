# R34 两阶段可视化与先看效果的执行协议

以用户最新要求为准：先交付观看效果，再开展新增消融。已完成的600步Extra/Coverage训练及复验保留，不重复训练；本轮主效果preview仅执行正确条件，不开启新的错时/错源训练或完整消融。Context代码和测试存在，但当前未训练且默认延后；不能把接口和零输出称为双端学习。

Module I：使用已核验的三首完整dunhuangwu2/3/4及冻结acoustic_v1槽位，重新构造E1-W候选并求全局路径，精确核对已有冻结研究计划。保存完整合法候选身份、来源、时间证书及不可行原因。SDMR全局/同步分数复用有公开哈希证据的实际历史缓存，重建相同短名单顺序和时间映射后绑定；分数标为不合格Shadow，不用于本轮选路，不显示成文化正确率。已有的E0/E1/时间可行域消融不重跑。

Module II：当前R34研究片段的真实Frozen/Coverage输出接入三栏观看。另对三首完整计划各固定首个拥有完整前后邻域的内部事件，编译真实Lodge输入并做一次预先固定的两噪声研究预览：当前事件的Source只在该事件的目标范围施加时间偏置；两侧读取计划中实际前一/后一事件的8帧planned身体，不用当前来源的长外围替代相邻事件。Root/C4缺失，Context输出零，结果是尚未合格的计划消费压力测试，不是已经学成的邻接或整曲。对三首音乐分别按其实际独立计划映射和音频切片编译，不复用第0首的映射。冻结R33与Coverage模型、采样器、噪声和音乐相同。每首2模型×2固定噪声，共12条256帧轨迹；不挑好看的种子。

每条生成绑定真实音频SHA、事件/来源、候选身份、时间图、窗口全局起点、原始音频样本起止、35D特征哈希、权重哈希及噪声。与规划联动必须所有身份匹配。没有生成的其他事件显示“尚未生成”，不得拿历史研究片段冒充同一计划的输出。完整计划预演由真实来源SO(3)映射和common22 FK组成，切换处明确为参考排列/待生成，不能称已连续生成。

统一离线观看入口：两个页签、同一个主音频时钟；三栏骨架均按同一整数音乐帧绘制，没有独立视频时钟误差。共同播放/暂停/拖动/倍速/前后单帧；暂停查看各栏实际帧号。原始来源原速播放采用独立30FPS时钟，必须暂停主音乐并标明，不为同步偷偷变速。参考图根据真实mask/时间范围显示，兼容96/256及变量长度。固定世界视图保留生成Root；局部姿态视图明确Root-relative，不用于隐藏世界轨迹。

交付包括整曲波形/拍点/槽位、候选与真实分数、原速/对齐来源、E1-W映射曲线、整曲计划骨架预演、对应实际生成及帧级误差/动态/Root/足部代理诊断。未知接触保持UNKNOWN，Native24仍NOT_EVALUABLE_22_OF24。所有动作展示保留同一视角比例、无平滑、无逐帧重居中/贴地；世界Root未知的来源仅展示身体相对姿态。页面完成后实际浏览器检查播放、暂停、拖动、倍速、单帧、页签及事件身份联动，并保留结果回执。
