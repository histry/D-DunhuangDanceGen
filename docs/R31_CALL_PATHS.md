# R31 动作合同、训练与复验调用

正式 EDGE、Planner、Native 与 R22–R30 模块保持冻结。R0 是 R29 的 COVER；R30 R1 不作默认。新研究代码位于 src/dunhuang/research/geometry_r31，通过独立模块与 run_r31_*.sh 执行。

A：audit 读取封存 COVER16 全256帧、4个历史适配持出、8个已认证 FineDance 窗和2个 ChangE 完整96帧Core。gauge 计算真实冻结 Scaler 逆仿射盒中的等价 row6D，保留所有无解位置与 NaN；只在等价编码自由度上优化，不平滑原旋转。Scaler 恒定分量不内缩，其他分量内缩1e-5，alpha/gamma稳定下界.05。实际无内缩盒的弱见证与第一旋转行符号矛盾证书另存；稳定下界失败本身不等于所有正范数表示均不可能。

A 未通过，目标-only训练不准入。新合同 CanonicalNormalizer 保留前7通道的原 Root/C4 合同，身体改为规范 row6D 的[-1,1]域。未知 ChangE Root/C4 保持 NaN，不提供生成真值。qualify 通过官方 FK 和相同差分模板检验新表示往返；初始 LegacyIO 的实际正确参考与 NoRef 轨迹必须精确重现冻结 COVER。

ActionIO 为身体输入与输出各加一个零初始化132×132线性增量。CanonicalIO 在每个噪声时刻使用明确的仿射噪声预条件，再走同一 Lodge 主干，输出回到新的规范坐标；LegacyIO 固定变换为恒等。两臂都训练参考编码与35112个动作I/O参数，合计300440。完整 q、预测目标、解码与50步采样均使用该臂的合同。噪声预条件是迁移初始化，并不声称新旧扩散分布完全等价。冻结音乐权重也不保证动作I/O训练后音乐行为保持不变。

train 两臂均从同一 R26 C1 权重初始化，使用封存 COVER 的16来源/8组、同1200步、同噪声时刻账本，每来源300次呈现。原 R28 目标保持不变，不增加物理项、不采用 R30 R1 局部读取。不以不同坐标下的6D MSE比较优劣。每臂保存0/1/599/1199步的真实更新前后读出，在新进程以零优化器调用复验。

evaluate 在四Train、四历史适配持出、两个种子上执行正确、错时钟、交换和无参考条件。各臂自身 NoRef 与冻结 R0 NoRef 分开统计：训练动作I/O后，自身 NoRef 可以改变，不能沿用旧资格或相对分母。主要指标始终对原始来源几何计算，包含 SO(3)、明确坐标定义的肩腕向量、绝对活动/幅度、配对 Root/身体 D1/D2/D3 与原有代理门；保留失败，不用新尺度重写旧结果。

probe 仅用四Train，在999/519/119/19时刻比较真实q与该臂实际反采样xt。重建、Root D1/D2、分部位身体 D1/D2 的梯度按编码器、参考输出、动作输入/输出分别读出，记录夹角、范数比、饱和和官方FK一致性。无优化器更新，不因探针读出自动安排第三物理训练臂。预测数组精确复验，80条完整梯度向量采用相对L2≤1e-5的数值复验，不能称梯度逐位一致。

change 使用两条历史 ChangE 原语和两首历史敦煌音乐；正确/错时钟/交换对照，未知世界 Root 和真实静态接触不评价。各臂自身 NoRef 在不同参考模式中必须精确相同；不要求其等于未经I/O训练的旧NoRef。来源保持指标仍是代理，不是新音乐事件真值。

release_r31 独立核验74个数组包、8对真实更新和80条梯度向量；统计首次与独立复采样各40调用/172轨迹。33段视频采用同一世界相机与比例，不平滑生成动作、不重居中或贴地。ChangE来源只有96帧观测Core，显示延长时只定格两端并标 DISPLAY HOLD ONLY，这些帧不进入训练或评价。CanonicalRoundtrip仅为表示往返，不是神经生成。

失败的第一轮恒定分量内缩审计、首次资格入口导入失败及恢复记录均保留。科学封存、回执和历史失败不当作临时SSH文件。公开统计不含权重、训练张量、原始音频和数据；视频按本批载荷授权后回传。完整Native24不可评，研究模型未晋升，新增整曲为0。
