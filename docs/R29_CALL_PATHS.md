# R29 调用、冻结边界和复验

正式生成入口与 R22–R28 历史实现保持冻结。新增模块仅位于 src/dunhuang/research/time_r29，启动脚本独立，不注册成正式生成器，不改变 EDGE、Planner、Normalizer、Native 阈值或原始资产。

model.TimeReference 继承有序 C1 编码器；新增的是无参数的 Core 时间偏置，参数仍为 265328。所有 97 个参考 token（96 个局部、1 个全局）保留。全局 token 与 Core 外偏置为零；每次前向从调用者的 mapped_source 读取显式时间映射，验证单调性与来源支持域。当前主实验使用来源原样时钟；尚未证明音乐重演或任意 E1-W 映射的生成质量。

parity 在 beta=0、启用仪表的情况下重跑冻结 B0=R28 T1 的真实采样，结果逐元素等于历史数组；B0 没有重新训练。readout 分别冻结原始规范参考、C1 和 T1 memory，训练三个有限时间卷积读出器；训练目标、Root oracle 和生成任务分开，不能由读出失败证明信息不可恢复。

train 从同一 R26 C1 起点训练 B1/F1，各 1200 步。B1 完全复用 R28 T1 的来源、时刻、噪声和损失账本，变化仅为 Core 时间偏置。FineDance data 使用 R28 已认证的真实官方预处理输出和本轮 35D 音频：001/002 训练，003/004 持出；每录制两个非重叠窗口，统计独立单位仍为录制。交换参考为批内循环交换，可能包含同录制的不同窗口，评价目标是精确来源窗口跟随，不宣称纯跨录制身份检索。

evaluate 对正确时钟、错置时钟、交换参考和 NoRef 运行实际 50 步采样，两组固定噪声。NoRef 必须精确恢复原模型；生成动作不重新贴地，不用来源动作覆盖采样状态。先逐窗口核验，再按录制汇总，不把两噪声或同录制窗口算成独立来源。

probe 从正确参考的真实逆扩散轨迹取 999/519/119/19 状态，重新前向的正确条件预测须等于保存轨迹，再比较条件干预。注意力只作描述；FK 固定 Root/祖先旋转是单一代表来源的诊断，不是生成质量提升或可加因果贡献。dynamics 在完全相同四帧模板上验证 world=Root translation+Root-relative 的 jerk 向量恒等式，后者仍含祖先旋转，范数不相加。

decision 将来源覆盖研究与整曲/物理准入分开。主 B1 Train 4/4、持出 1/4 触发一次固定 16 录制/8 音乐组 COVER；coverage 先封存哈希选样清单，再训练同起点、同总预算 1200 步。每来源 300 次呈现、每来源/噪声时刻 6 次，不宣称与小集同单来源剂量。原持出四音乐组全部排除，不按 Native 或生成表现筛选来源。不再增加预算或按持出调参。

change 固定历史两 ChangE 原语、两音乐与种子，比较神经参考控制。Root、真实静态接触和跨模态语义真值继续 UNKNOWN；只报告可比旋转、局部几何与运动学代理。完整 Native24 因关节合同不完整保持 NOT_EVALUABLE。

run_r29_initial / training / evaluation / coverage 分别启动新阶段、写唯一回执并独立复验。run_r29_finish 调用 release_r29 核验全部数组、实际更新读出、摘要及冻结代码，再生成固定 42 段对照视频。视频用同一世界相机和比例，无平滑、生成后贴地或逐帧居中。网页同步控件仅做静态脚本检查，不冒充实际浏览器验证。

先发布代码再在服务器 tmux 执行；收尾发布公共统计、哈希与报告，模型/张量/原始音频不进入 Git。新视频按批取得回传授权。只清理本轮实际创建的临时 SSH 辅助文件，科学日志和失败回执长期保留。
