# R34 连续敦煌身体覆盖与上下文研究

基准 db0d121。研究模块独立于正式 EDGE、历史 Lodge 和 R33；不更换主干或音乐接口，不修改旧权重和科学封存。一个冻结 Lodge、固定 Canonical ActionIO、冻结 General 来源；ChangE 从 R33 Dyn 开始。R34首项改变是请求控制和真实目标的时间范围，不是单独某项损失消融。

## 真实来源与时钟

人口先保持 female_FeiTian 与 male_pipa_1 两条已适配录制。旧96帧Core时钟逐帧保留；两侧按观察到的首/末一步速度延伸至完整256帧，从同一连续原录制读取SO(3)，禁止定格、循环、不连续事件拼接、替换挑优。额外读取一个真实halo帧，目标时钟重采样后求角速度，避免窗口首帧人为零速度。核对原NPZ轴角与继承Catalog旋转，保留原始来源SHA、录制、完整位置向量和半开帧区间。Root/C4仍UNKNOWN；它们虽然可能存在原始文件字段，但其世界/接触合同尚未准入，不当作完整x0真值。

变量N的来源编码保留相同265328参数；N=96走原R33操作，需完整采样精确复现。N=256使用256局部token加全局token，显式Bx256目标到来源映射及控制mask。阶段通道仍零，不称语义阶段控制。真实身体目标、可编辑域、请求改变域分别保存，监督与差分只消费有效观察；被新身体目标覆盖的范围解除身体NoRef保留，未知first7的教师系数保留原设置。

## 固定对照及准入

预检先做：原始来源/时钟/全身22关节支持、Legacy对R33逐位相等、General/NoRef恢复、两次只用训练来源的真实有限AdamW更新。不得把未知Root补零形成扩散x0，FK零Root只作为相对坐标规约。预检通过才启动600步主对照。

Frozen=不训练的R33 Dyn + 原96帧参考；
FrozenFull=同权重读完整256帧参考，不训练；
Extra=R33 Dyn继续600步，原96帧目标和窗外保留；
Coverage=同权重、同600行日程，完整256帧连续来源和目标，Context冻结。
主干、IO、General、Context固定；两组仅连续覆盖方案不同。保留R33的16条AIST回放、各75次呈现，原训练时间/噪声/丢弃/优化器设置相同；第300步分别刷新当前条件的实际访问状态。初始访问状态也分别由实际Legacy/Full参考采样得到，不把条件不匹配缓存说成在线状态。使用R33已冻结动态尺度和系数，不按R34评价调权。

评价在完整50步采样上进行，正确/错时/交换/空参考、相同音乐和噪声。原Core、前侧、后侧、全窗分别报告SO(3)、肩腕向量、活动/幅度、Root-relative配对D1/D2/D3、身体/世界/Root Jerk，专门报告跨63/64和159/160的完整差分模板。R33额外莲花/静思不加入本轮训练，不宣称本轮扩大了目标域人口。

覆盖稳定的研究准入预先固定为：两条来源Core SO(3)和肩腕误差不超过Frozen1.1倍、Core活动/幅度相对Frozen在0.8–1.25；新增外围SO(3)至少优于同预算Extra10%，跨边缘D2误差低于Extra。该准入只决定是否开展独立Context试验，不是Native或整曲资格。

## 条件上下文阶段

覆盖通过上述稳定门槛后，冻结Coverage来源分支，单独训练现有Context；否则写明阻断原因，不在失败覆盖上叠加训练。上下文协议需显式窗口全局帧原点、局部时钟、共同世界坐标身份及逐通道观察mask，左右片段不能进入待生成缺口。随机缺口、单侧缺失、部分身体及右侧Root未知分别注册。真实完整AIST可q_sample完整目标；部分ChangE只对模型实际访问状态做身体监督。

固定相同目标/音乐/噪声，比较正确双端、去左、去右、合法姿态错配、固定来源改变上下文及固定上下文改变来源。检验真实缺口与跨界改善，不能只凭输出变化或硬覆盖端点认定成功。未经验证不做相邻两事件或三首整曲，不新增风格编码器/分类器，不重训主干。音乐逐首独立重定时和更多录制人口属于后续独立对照，不混入本轮覆盖结论。
