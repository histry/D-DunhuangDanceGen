# Paper1-MinimalContextEdit-P3

代码基线0a7e9ef；P1已测图、P2主实验与控制清单均哈希冻结。研究全部14个固定失败中心任务，中心候选UID域与P1相同，不改音乐槽位、来源区间、q、数值门或UNKNOWN状态。

主方案为精确分层DP：先最少来源原语变化，再最少同原语实际采样q变化，最后完整UID序列字典序平局。原语身份为source_uid、event_uid、source_interval；不把同一录制中的不同区间误算成保留了同一原语。变化数包含指定中心，另报排除中心的上下文变化数。标签保存所有节点的Bellman距离、前驱和最优前缀；检查全部等式与终点最小值，并以小图穷举交叉验证。最优性仅限同一有限已测合格G1图。

主观看先展示B0／P2已保存强顺序／Min-Edit＋Warp次目标，复用本机已授权P2播放数据及音频；新数据只含新增主路径与原速来源。每条新路径从Native重新采样、用P2冻结装配器和指标重建，所有Bridge均重新物化且原哈希、数值读数精确一致。每阶段最多512种边界物化，不调用新的未知边，不按动态或观看结果挑路径。

主观看浏览器验收后，才做Source-only次目标消融：只最少换原语，再按UID平局。两者精确最少来源数应相同，主方案同来源时钟变化应不更多；这是目标定义的可核验性质，不是艺术质量收益。保留原B0每首9G0／3G1混合策略的原数组，不将它当成全G1图内已知路径。

每阶段新tmux进程独立重做DP证书、来源读取、G1物化、整曲SO(3)、FK、来源映射及全部统计，逐文件精确比较并禁止优化器。无路径案例、已测图与连续域的差别、三首历史音乐曝光、Root／Contact／Native24和艺术质量不可评均明确保留。旧P1／P2待授权JSON不自动公开，新增媒体和标量按批处理；只清理本轮临时SSH辅助文件。
