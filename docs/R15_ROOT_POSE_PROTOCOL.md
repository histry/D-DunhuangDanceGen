# R15 预登记：受保护的 Root–Pose 联合容量

基准 bfb269dfb5714a2c012d10d57f4511509c82a621。独立包root_pose_r15；
R13、R14及旧R9代码/权重/人口/Native阈值不变。先P0/P1，不预建未经资格的新模型。
主要研究单位为8个已经曝光的Train音乐组，不能称未见来源泛化或盲测。

## P0 固定编辑域与责任

逐文件核验R14的504文件manifest和公开封存报告。
保留旧4个monitor所有案例及两个模型最终左右接缝分解；
特别保留0左、2右、3两端，不用均值掩盖失败。
重新对旧4窗与R14-P2的8个固定Train窗原始动作计算Native/FK。
只有四帧FK Jerk模板完全在[60,90)外且超过原全局最大门限才给必要EXCLUDED；
否则UNKNOWN，地面/足滑/接触/支撑人口等均UNKNOWN。
局部机制门与完整Native绝对门分开；严格排除窗仍可参加机制研究，不寻求30帧内完整资格。

## P1 固定人口与路径

复用R14-P2八个固定Train窗、每窗t519/19自身轨迹状态，不生成新基线、
不换窗口、不读Val/Test选方向、不拟合预测头、不更新模型参数。
新方向使用真实配对未知动作作为Train容量Oracle，明确区别于R14的A2参考引导；
该Oracle不是真实音乐推理条件，也不声称复现同一R14损失。
原音乐、真实8+8观察、Mask、x_t及R13权重在所有对照中一致。
J0预测必须逐字节等于R14保存的同状态无引导预测。

|组|允许改变的未知x_t输入|目标|
|---|---|---|
|J0|无|冻结原始预测|
|J1|Root位置3D、Root朝向6D|真实配对Root轨迹/朝向、两端D1/D2误差|
|J2|J1 + 髋1/2、膝4/5、踝7/8六维旋转|与J1完全相同|
|J3|与J2相同|J2目标 + 世界足端位置和跨帧速度一致性|
|J4|与J3相同|同角色跨音乐组置乱Oracle标签|

J1输入270维，J2/J3/J4输入1350维。它们是输入权限，
网络会产生全身输出响应；没有把Root/其他关节输出冻结或复制回去。
所有方向总L2预算相同，为0.02*sqrt(270)，避免维度增加自动获得更大剂量。
J4供体跨音乐组、保留人口，Root相对左端观察在接收者左端SO(3)坐标系表达；
真实硬边界和外侧全150帧不变，不能用坐标错位制造容易负例。

目标单位：Root位置0.1m、朝向矩阵0.3、跨接缝速度3m/s、加速度30m/s²；
世界足端位置0.1m、速度1m/s。四个足端为7/8/10/11，
用真实配对动作的FK监督，不使用预测接触作静态足部真值。
FK实现复用R14已检验的Torch算子，本轮每窗再次与Native完整150×24关节核对≤1e-5m。
每个方向中心差分eps0.001，要求相对误差≤5%或绝对差≤1e-4。
方向可用未知配对目标，原模型真实上下文始终不含未知目标。

每方向固定试1、1/4、1/16、1/64四个预算比例，非自适应超参扫描。
全保存，按先后接受第一个满足自身目标下降、物理信赖域及实际保护的候选；
全部拒绝则回退J0，回退不计成功，保留原分母。
这只是在Train上登记的有限容量线搜索，不是推理控制器。

实际回接输出相对J0逐帧最大限制：
Root平移0.02m、Root转角0.05rad、允许下肢转角0.05rad、
其他局部关节0.005rad。编辑域外Native原帧必须逐字节不变。
输出响应保护不同于输入掩码，不能混淆。

每个候选真实前向后，左右接缝Root步长、转角、足端最大步长和Peak Jerk
均不能增加超过1e-5相对容差；左右Root位置/速度/加速度误差同样逐端检查。
来源全身平均姿态误差最多增加0.005rad，上身与Root朝向误差最多增加0.001rad；
活动度相对J0变化≤5%。Root和世界足端RMSE都必须严格改善，零更新不算成功。
不以减小运动幅度或牺牲另一侧换均值改善。

P1合格：J3在至少6/8组的两个固定状态都满足上述保护且被接受，
合格组数严格多于J1；相比J1和J4的组均足端相对收益均≥2%，各至少6/8组胜。
所有8组均进入对照计算，拒绝候选仍计原J0结果。
完整Native逐个原阈值报告，但不作为局部机制准入的替代。
局部通过也不是生成/部署资格；仅能另登记最小Root–Pose反馈训练。
任何导数/FK不通过时先视为数值检查失败，不据此下算法无效结论。
