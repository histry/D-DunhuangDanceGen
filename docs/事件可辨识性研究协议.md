# 事件可辨识性：冻结编码器、弱监督与合成真值

基线代码 bc8f241。历史 A/B/C 权重和报告冻结，不追加训练或重新选择。复用最终 clock_root_04 的完整音频、连续动作、已独立重放的时钟和固定 SDMR 编码器；不重新提取 Jukebox，不改变 50D/74D 编码器、EDGE、Root、Native31 或默认规划。

## 实现与证据身份

- event_targets.py：完整源音乐起音、重音、节拍、低活动；动作启动、速度峰、减速、转动、定格候选。角速度与 FK 线速度的一致性仍是运动学代理。接触、肌肉发力和艺术意图 UNKNOWN。
- event_data.py：核对源 SHA、角色、连续支持，固定120帧实际 core；15Hz Token 最后实际观测在118/30秒，不外推第119帧事件。128D Token 加16D显式事件描述，描述量归一化仅用Train。截断、掩码、选择规则保存。
- event_weak_labels.py：0.5秒候选带宽内，音乐/动作检测器一致、总计至少两条同条件重复录制（含当前录制）、重复支持率不低于0.5、显著性不低于0.4，才产生低权重PSEUDO_MATCH。时钟、显著性、重复支持分别保存；允许多个候选共同承载概率，其余UNKNOWN。缺少可靠拒配覆盖证据时不生成PSEUDO_NULL；NULL学习来自合成精确标签。
- partial_path.py：双侧可丢弃、严格一对一、非交叉部分路径；可微全路径配分函数训练、硬最优路径解释。受Drop-DTW启发，但不是官方多对一Drop-DTW复现。软边缘分布可跨多条路径，不能声称每条软边均不交叉。
- event_perturb.py：同模态复制，随机删除两个、插入两个其他来源组的真实Token，两侧长度相同，保存身份与合法单调变换真值。仅验证合成身份/拒配/时间恢复。跨模态±8/±15/0帧来源时钟分类单列，不当作语义事件真值。
- event_metrics.py：来源时钟代理、合成指标、人工评价分开。未审标注拒绝进入人工指标；需两名审核人、源SHA、时间支持、明确NULL/UNKNOWN。
- event_replay.py：新进程重建完整源事件、FK、弱标签、候选、事件Token与算子对照，重算全部头/探针预测，禁止优化器。

## 固定对照

配置 configs/event_identifiability.json：种子20261121、每组400更新/batch12、同采样与候选表、最后一步权重，无Val选择。完整来源组轮转；旧六组运行并无遗漏，每组1600次，通用采样缺陷不能解释历史失败。

新组：冷启动Sync、新NULL-OT、严格路径D、D+合成时钟/路径/NULL的E、E+弱对应F、E+打乱弱对应负控制。OT与路径组投影/NULL参数、初始化一致，Sync参数量单列。历史A/B/C仅用于固定输入算子敏感性检查及历史参照，不对不同任务数字直接排名。

损失：来源时钟多正例检索 + 0.25合成偏移分类 + 0.25合成路径似然 + 0.1合成NULL + 0.1弱对应（按组启用）。同音乐同时间不同录制为合法多正例；同音乐不重叠错时、不同已知组的能量相近候选是辅助对照，不表示艺术上无效。弱标签打乱限有效带宽，保留权重/支持。

Clock-only、nearest-time、energy、置零、内容逆序、固定网格内容交换均保留。独立合成验证种子与Train扰动分离。raw74、TCN、Transformer、FK各用相同387参数线性探针、相同60时间点、Train归一化和预算，预测FK速度代理。FK输入不含目标聚合速度；Root不在74D中，其差异不证明压缩损失。

## 执行、资格与复核

先推送代码，再服务器拉取，tmux执行 scripts/run_event_identifiability.sh。完整哈希、分组、有限值、精确机制fixture预检后才训练。保留测试日志、执行SHA、开始/结束时间、退出码；新目录不覆盖失败。公开结果只经白名单导出聚合，完整源身份和私有路径在忽略目录。

Val仍只有两个已曝光关联组，历史Test不改称盲集。本轮不使用Test，不接正式Planner，不执行无资格的新生成。八个源片段空审核包只是工程模板。将来约200片段盲审需来自未参与设计/调参/选择的新来源，音乐单独、动作静音、联合判断三个阶段，两人独立，冲突第三人仲裁，保留UNKNOWN。

缺少人工审核时真实EventMAE、TypedEventAccuracy、真实NULL P/R、真实风险覆盖不可评价。合成风险覆盖明确标注SYNTHETIC_TRUTH；显著性与模型得分不等于校准正确概率。所有头保持operational_qualified=false，是否改善取决于实测。
