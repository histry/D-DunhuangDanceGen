# R20读出命名补充（原结果不修改）

R20报告表头“CFG前”对应源码preclip，实际是2 cond-unc之后、clamp之前。
原unc/cond读出才是两个CFG输入分支。原数值、代码和失败结论保持封存。

R20 legacy interior排除了跨8/75/112/150/217的四帧模板，保留了首尾完全硬固定区域内模板。
它不是完全可编辑区域。canonical225下历史模板数207；
按实际硬Mask分区为完全固定10、跨界6、完全可编辑206，合计222。
这些集合含义不同，不应只比较数量误认为同一人口。

R21新增cfg_preclip命名和固定/跨界/可编辑三分区，同时继续保存legacy读出。
这不是删除不利模板，不改变原Native或回写R20资格。
