# Paper1-SDMR-Integration-P0

冻结起点 `17bb6df3107498f472e87f2fb8bd3baf5bb200cd`。本轮实现 `python -m dunhuang.paper1.run preview`，先交付观看，再 `controls`；两个阶段分别以 `replay-preview`、`replay-controls` 在新进程精确复验。

- 复用R56 B0三首历史开发音乐、各13个Core／12条48帧Bridge、原16来源单位。逐槽最多两条执行时钟：原E1-W与R53原成本前64路径中的第一条不同逆时钟。无第二条时保留1条，不复制填充；非法来源保留失败。不新增训练或正式Planner调用。
- 所有候选实际SO(3)重采样，多锚点证书覆盖其完整PL时钟。事件提案最多3个，Uniform邻域15帧、技术容差3帧、NULL允许；提案共同证书与已执行候选证书分开，未执行提案不冒充新动作。输出同类事件重新检测误差仅为代理诊断。
- 先重建三首冻结整曲数组并校验Core逐帧一致；完整Bridge继续来自已封存父轨迹，注明实际G0/G1身份。本轮新候选不继承父连接资格。
- 观看验收后，再用冻结R41编码器／原Train Normalizer、R67 Single64／Multi64，按候选实际目标时钟重新编码。来源级粗评分使用E1-W执行后的全局局部Token均值，明确不冒充原训练全局头。实际／另一歌曲同绝对时间／raw输入置零共享同一有效帧支持；不填造音频末端特征，不隐式执行第二条Warp。
- GTWLocal成本同来源自然速度参考；为每条候选分别实测其与冻结左右邻居的G1，不回退、原门不变、记录请求／缓存／实际构造数。该局部资格不代表所有新候选之间可连接或全曲替换路径已生成。理论局部请求上界2496，独立硬上限相同。
- SDMR-A只写Shadow排名，不删除来源；SDMR-B只写共同池评分。`can_route=false`，没有独立艺术、语义或Native24资格。FGMMC不重训、不改图、不改冻结输出。

本轮是两份执行方案明确指定的P0先导，不运行后续P4全候选图搜索或P5训练。比较证据仅覆盖共同登记候选域及历史开发音乐，不声称新音乐泛化。所有私有旋转、身体坐标、音频、权重留在输出目录；按批核验并授权的观看材料与标量结果另行交付。
