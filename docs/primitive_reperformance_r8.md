# R8：来源演绎与双向 Bridge 的独立资格检查

基准2a7941859c381a0308b7288797b4f443a7b6c711。遵循用户本轮窗口重新生成与敦煌舞风格缺失方案。代码分别在research/primitive_reperformance和research/bridge_inpainting；正式sampling.py、event_music_adapter.py、physical.py与历史数据不改。未引入Root网络或未合格Adapter，未训练新的风格编码器。

## 来源线

先对保存R7做原始拟合ChangE、E1-W重定时、真实EDGE输出的三方骨架诊断。使用同一Native几何、同一相机、22个实际拟合关节和明确的Root/手指未知标记。原始源与目标长度不同，原始源按原30FPS播放；面板结束保持最后帧仅为展示，不冒充新观测或质量修复。

原数据具有0–21旋转观测，腕20–21可用；22–23及手指没有来源观测，Root平移/接触没有可信来源标签。完整Core依照已有E1-W单调映射逐帧SO(3)重采样，保留全部已记录的自动阶段。阶段是运动学代理，非文化或肌肉发力真值。

研究在同一冻结EDGE的每个反向步中施加软SO(3)条件：基础强度.55，阶段高斯增强最多.15、宽度3帧，边界6帧C2衰减到原强度.3倍，首尾仍为非零条件。S0是旧12–19关键点±12帧Temporal；S1为12–19完整阶段轨迹；S2加入腕20–21；S3为全部已观测22旋转，覆盖躯干、下肢及初始朝向对齐后的来源相对转向。Root平移、接触与未观测手部保持生成量。不是直接复制或后贴来源帧，也不是已训练的新Adapter。

参考值不按目标Scaler裁剪。模型提案保留原6D向量尺度，在SO(3)上按固定1至1/256的九档回退，仍不能满足原Scaler支持域则保留该关节原预测并记录拒绝。该机制不授予缺失观测资格。

从8个原始来源固定组成4对，前2对与后2对来源不重叠；按种子20261117的哈希顺序选第一个完整、合法、75–150帧Core配对，不按Native或模型效果筛选。两首已曝光敦煌音乐的真实首个Jukebox窗口用于单事件诊断。为隔离模型对音乐内容的响应，两个音乐条件共享同一合法参考时间映射，不把这项控制称为音乐协调性真值。

每对每音乐一次无来源基线，S0–S3各两来源，共72次短窗生成，全部在新进程重新生成和Native；不是144个独立样本。关注完整来源角误差、阶段姿态、腕部旋转、肘腕Root-frame轨迹、躯干、停顿代理、活动度、相对另一来源的改善及直接音乐条件响应。门限在查看生成前固定在config.json：S3全部16条必须通过来源、腕/躯干/轨迹、相对转向与活动度标准以及完整Native，8组音乐反事实响应必须达到.02rad。人类文化风格真实性保持UNKNOWN，不阻止客观实验。

## 边界线

B0复用全部十条R7保存输出，对比原始反归一化去噪窗口、装配Root、官方FK与NativeFK。最早可观察的阶段是保存的去噪窗口，不能宣称已定位到未保存的某一反向扩散步。

固定四例：wu2基线、wu2/3/4主计划A，均检查第75帧，未知编辑区[60,90)，两端连续观测[52,60)、[90,98)。实际生成的Root与全部24旋转是上下文数据，不是ChangE来源真值；接触预测不作为硬观测。必须严格通过原归一化与往返检查，不支持者拒绝，不补充其他更好案例。

比较原始、九帧三阶Savitzky–Golay流形/Root平滑控制、无来源双侧Inpainting、带完整来源阶段的双侧Inpainting。后两者使用同一冻结EDGE、固定原音乐窗口和同一随机噪声。复用项目50步constrained_ddim的逐步带噪观测/最终干净观测恢复机制，不声称精确复现官方1000步DDPM；官方inpaint_loop末步使用x回退，研究入口明确恢复干净已知上下文。来源只影响中间未知区，硬上下文优先。

只将获准编辑中间区接回原全局时间轴，所有其他151D数值逐位不变。重新核验整个实际装配动作和150帧ROI的原Native，比较中心Jerk、两个新接缝及来源保真。局部门要求中心P95下降至少10%、接缝峰值不升、来源误差不退化、ROI完整Native通过，四固定案例全部满足才通过Bridge门。原整曲Native失败不被相对改善抹掉。
