## P1：真实连续AIST++人口

仅用R13原1399窗/36组fit人口，不用Val/Test筛选。
按seed16041的组SHA固定选首4个具有连续对的Train音乐组，各按源SHA/起始帧SHA取一对。
必须同recording_uid、原始动作SHA、完整native源SHA、音频SHA、clock SHA和role。
相邻150帧起点相差75，均来自同一真实225帧连续录制，不能跨录制拼接。
要求原始前后8帧真实评价Halo，不补零，不按生成结果换案例。

逐一验证官方校准状态、音频偏移、Jukebox producer样点区间/Layer66/30Hz和SHA；
实际两段原音频重叠样本必须逐值相等。
独立crop的Jukebox重叠特征可能不同，报告最大差异，不冒充同一上下文提取。
统一225帧音乐采用登记的“先出现crop拥有重叠时间，后crop仅补最后75帧”，
保留原两份150帧特征与producer以便审计；不是完整上下文225帧Jukebox提取。
未来C2消费统一225帧切片，不能两窗口各自重定Root原点。

AIST两事件仅为同一录制的连续来源段代理，边界按案例固定50/75/100/75。
不是人工语义事件或经验证音乐乐句。关键帧为两段各自中点的3帧局部上身观察。
源条件与其身份时间映射核对，未知重建目标不进入观察Mask。

## P2：C0/C1生成合同

每案例同seed、真实Jukebox、R13冻结权重、50步CFG2和同一150帧输入规格。
C0：原[60,90) Bridge，52:60/90:98真实8+8观察，硬采样后按旧合同回接原父。
C1：全部150帧由模型生成；第一/末8帧的真实Root/24姿态作为软观察，
另加两个来源段中点upper8关键姿态。无硬Mask、无输出Root或姿态覆盖。
这改变生成任务，不是放宽R15旧半径或在旧结果上扩大权限。

五个C1组：
correct；移除事件关键姿态但保留两端；跨组错配关键姿态但保留两端；
跨组错配两端上下文但保留关键姿态；固定动作条件更换音乐。
供体为已固定4个不同音乐组循环置换，Root以真实首观察坐标对齐，避免任意世界平移。
换音乐用于响应诊断，不等于艺术上错误的舞蹈。
条件不能超过原Scaler支持域；不截断源姿态或根据结果删除不支持案例。

所有组的完整反向噪声指纹必须一致；R13权重不更新，未知真值只用于预定义源观察
以及最终评分，Mask以外值在采样输入中清零。保存每组50步raw x0、条件/Mask及最终动作。
24次首次150帧采样、24次新进程重放；C2/整曲0次。

### 新外侧边界不能被隐藏

Native分别评价150帧结果与真实8+8外侧回接的166帧序列。
C1窗口两端保留真实外侧原帧，不用平移/旋转修复或平滑后处理。
旧60/90接缝、真实代理事件边界、0/150外侧边界分别报告。
C0保留120帧原父，所以仅在共同生成的60:90内比较来源姿态，
不能把C0全段接近真值当成公平的生成优势。

P2准入每例须同时满足：
correct的关键姿态误差优于移除与错配；两端Root误差优于错配上下文；
公共中心[45,105]的最大FK Jerk相对C0至少改善10%；
共同生成30帧姿态不恶化0.05rad；
观测Root RMSE≤0.1m，活动度/真实源在[0.5,1.5]；
两个新外侧接缝各Root步长≤0.05m、足端最大步长≤0.15m、
跨接缝Jerk≤原Native最大Jerk门限（从环境读取）。
至少3/4例全部满足，才允许另登记C2最小跨窗口状态训练。
这些是新局部机制条件，不替代Native完整绝对判决或新风格资格。
缺一例或缺一组都不能改变分母。
