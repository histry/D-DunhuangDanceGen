# HoldTiming-Q01

This isolated research branch audits frozen R69/R73/GTW executions against actual natural-speed sources, then tests a finite common proposal pool. It does not alter Planner, E1-W, G1, SDMR weights or Native thresholds. R74 remains not started.

Low activity is a body-relative kinematic proxy. World translation, fingers and artistic hold roles are unknown. Angular/FK thresholds and the fixed duration cap use only the four frozen R47 Train recordings. The minimum detected run length is a detector support rule, not a maximum acceptable pause. Source holds are detected over the full recording before cropping; censored runs and pose drift are preserved.

Run from the repository root in the historical edge environment with PYTHONPATH=src, OMP_NUM_THREADS=1 and OPENBLAS_NUM_THREADS=1, using tmux and retaining each exit code:

```bash
python -m dunhuang.research.hold_timing.study
python -m dunhuang.research.hold_timing.view
# Actual browser acceptance must bind receipts/preview_browser_acceptance.json to audit/manifest.json.
python -m dunhuang.research.hold_timing.attribution
python -m dunhuang.research.hold_timing.controls
python -m dunhuang.research.hold_timing.view --controls
python -m dunhuang.research.hold_timing.verify
python -m dunhuang.research.hold_timing.release
```

The preview retains all twelve historical display cases and missing arms. Source playback has its independent original 30 FPS clock; target executions share the actual audio clock. Complete original recordings have a separate player. Controls reuse that original-source page rather than duplicating its body data.

Controls reuse all four doses of the R73 finite legal proposals plus explicit E1-W/Uniform. They do not impose the historical GTW fixed-peak stratum: this is a different hold-selection task. Saved proposal GTW costs are reused only after code and actual clock/rotation checks; baseline costs and frozen R41 Single64/Multi64 readouts are computed. All displayed candidates get new G1 solves, and full scientific replay recomputes the executions independently.

Hold-first rules use an explicit lexicographic ordering; their duration cap and music allowance are uncalibrated mechanism hypotheses. Correct/wrong music score the same actual candidate pool. GTW/Multi64 Pareto readouts are saved, but without independent preference and a calibrated SDMR margin, fusion abstains to E1-W. All artist-quality conclusions remain NOT_EVALUABLE.

If the whole supported source interval lies inside one low-activity source span, every monotone full-support map occupies that same source content for the full target budget. Crossing a velocity threshold after speeding up is not proof that inactive source content was removed. Genuine content changes require a different supported source and lie outside this frozen pilot.

Current GTW is a documented adaptation, not a complete reproduction of its original DP. Official GTW already discusses silence removal; pause compression itself is not a novelty claim. Private output archives retain motion, media and provenance; public release contains scalar diagnostics only.
