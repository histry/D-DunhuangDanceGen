# FGMMC-Q01 finite-clock learning pilot

This isolated pilot reuses TemporalBlock and strict partial DP. It learns 50D music versus 274D observed pose/geometry/dynamics with explicit masks; absolute progress/duration channels are removed. No semantic role compatibility table is used. Five globally rate-legal, edge-preserving clocks constrain latent partial match paths during training. Per-clock zero-content log-partition subtraction removes path-count offsets; log-mean-exp over deduplicated clocks controls candidate multiplicity. This is a finite candidate method, not complete continuous-time inference or a new Soft-DP algorithm.

Metadata-only genre/dancer blocking is frozen before tensor access. AIST official Train is divided into new train/dev/holdout partitions; music, raw capture, known choreography, genre and dancer do not cross. Historical exposure remains disclosed. Original AIST full-audio features and recomputed rotations reconstruct raw observations; new statistics use only the new Train population. FineDance archive-common-clock data is diagnostic, not dancer-certified and not used in this pilot's optimizer.

Run prepare; train Feasible for fixed300 steps; publish actual three-source candidate playback first. Then train OrdinaryPostFilter and ShuffledPair with identical initial weights, schedule, budget and architecture. Evaluate final checkpoints once on all registered windows, reporting zero/reverse/wrong-song, audio-change-density and position-only controls and group intervals. Ordinary learning has unrestricted latent paths, but all models use the same finite feasible bank at evaluation. No checkpoint is selected using DEV.

Actual ChangE visualization scores already executed RoleAlignment rotations after rederiving their features; scoring is uniform-clock on the actual output, so there is no second unexecuted latent Warp. Frozen parent G1 proofs are tied to exact full-rotation/bridge hashes, with no inherited qualification for a new motion array. This is Shadow inference, not validated target-domain learning. Independent replay reloads weights and recomputes inference and scalar ledgers with zero optimizer steps; it does not claim exact independent retraining.

Commands: `python -m dunhuang.research.fgmmc_q01.train prepare`, `...train Feasible`, `...preview preview`, `...train OrdinaryPostFilter`, `...train ShuffledPair`, `...evaluate`, `...preview controls`. New planner runs and whole-song assembly remain gated; Native24, artistic quality and semantic roles stay NOT_EVALUABLE. No EDGE, Diffusion or evaluation-network training.
