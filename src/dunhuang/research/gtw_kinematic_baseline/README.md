# GTW 适配基线的冻结资格实验

参考 [Guided Time Warping, SCA 2007](https://people.csail.mit.edu/jovan/assets/papers/hsu-2007-gtw.pdf) 第3.2节：躯干坐标中的姿态、速度、加速度与自然原速参考的3近邻平均距离。本实现采用共同22关节SO(3)来源、胸部坐标、3帧位置预滤波、参考独立RMS块归一化，以及已有R73有限合法候选。不是原论文离散压缩DP及输出后滤波的完整复现；不改变来源空间路径，不用同一优化分数证明感知改善。

协议A：全部方法共享R73合法候选，在评分前按实际输出峰选择距固定目标最近的单一峰位置层，然后分别用Local、Extended、Context排序。Extended加入局部SO(3)速度／加速度与FK Jerk；Context再增加前后各15帧运动特征。没有人工标签，阶段语义始终UNKNOWN。

协议B：同一有限提案域、相同来源重采样预算，每种方法独立计算步长4粗查询，再对自己前4条执行完整查询。原候选姿态可共享缓存，但粗查询和精查询实际重新执行并记数。不是新连续Warp生成器，不证明GTW原算法性能，也不是A中纯特征增量的替代证据。

先执行`python -m dunhuang.research.gtw_kinematic_baseline.study`取得12组+6帧协议A观看结果；浏览器验收回执与预览manifest匹配后，`--controls`才允许原四剂量及协议B。每条展示执行重新调用原G1；Uniform可能改变保护边缘，独立标记，不与严格内部干预混为同任务。E1-W／Uniform是未强制+6目标的参考，三种GTW的主要比较共享实际峰位置与候选池。

`--replay`在新进程独立重算，科学输出精确比较，耗时独立保存不纳入字节封印。历史R73只读。无真实偏好时，不做M0/M1/M2偏好训练，不宣称上下文收益，不进入R74。2006物理重定时缺少Root／接触／动力学观测，保持未复现。
