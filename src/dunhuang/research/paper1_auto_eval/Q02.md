# 有边界的自动评价资格 Q02

Q01生产器与所有基线保持冻结。Q02是同一评价包中的独立版本，不使用艺术总分，不训练网络、不运行Planner、不重新生成G1。

先在GitHub发布协议与代码；服务器同SHA运行preview，回传实际数组观看并验收后，再运行音乐时钟和运动控制评分。

```bash
PYTHONPATH=src python -m unittest dunhuang.research.paper1_auto_eval.test_q02 dunhuang.research.paper1_auto_eval.test_contracts
PYTHONPATH=src python -m dunhuang.research.paper1_auto_eval.q02_run preview

# 新进程完整重跑固定Beat This!与控制数组／评分

PYTHONPATH=src python -m dunhuang.research.paper1_auto_eval.q02_run release
```

Q02-A仅从现有R59的Train/genre-train诊断元数据选每域最早6条不同音乐／录制／已知编舞，排除Q01已用的音乐、原始动作、录制及已知编舞。它们是新增到本BAS指标的人口，存在早期项目曝光；不能称新测试，未知编舞关联不制造为已隔离。失败不替换。FineDance官方档案同起点不升级为波形校准，另留dancer角色。

固定5时钟、非循环共享支持；同时报告严格唯一Top-1、并列分配Top-1、成对胜率、错音乐六候选排名。能量相关与相同运动事件数的四相位均匀网格是基线，四相位全部保留，资格只使用预登记phase0。记录时移距整数节拍周期的距离，不能把周期相容性当成有身份事件正确性。每域相同组配对bootstrap要求BAS的Top-1相对能量与phase0密度基线的下界均大于0且全部登记组有效；即使通过也不认证艺术质量或未见泛化。

Q02-B复用6条原速ChangE来源，正式登记SO(3)与完整编辑模板指标；保持静止、合法保持延长、速率折点、跳时、重复姿态、肘关节跳变，以及3剂量腕噪声／小幅节拍周期振荡。小振荡按固定音乐周期构造，不搜索BAS最大值；是否得分上升是观测结果。所有剂量均报告。合法定势和保持延长没有艺术错误标签。静止控制明确允许全片写入；其余按具体mask核对源外数组不变。腕轴包含父链，局部旋转差不等价于全局方向差。

Q02-C预登记所有参数和读域，动作、来源与时钟共同身份；缺少Root/接触、独立语义或感知真值仍不可评。MotionCritic不下载／不推理；联合来源×时间仅在音乐资格及执行条件支持后另行实验，不能用本轮代理敏感性宣告联合编舞质量。
