# RoleAlignment-Q01

这是有限事件对应假设的Shadow资格实验，不是新的自动质量评委。旧Reachability、SourceTime、Q02、E1-W、GTW、G1生产器冻结。

从完整来源R47提取上身角速度正变化峰、上身速度峰、方向变化和保持区间结束；允许1–3节点、同类节点及缺失。音乐目录独立冻结。角色映射只是可检验假设，独立角色记录0，语义准确性不可评。ChangE固定既有3条S0来源及240/240/360帧预算，源节点根据本身位置选代表，音乐候选根据其Uniform投影附近最多15帧提出，不再把最早Onset强行放到音乐1/4。

所有方法共享Typed及NoTypes的有限提案并集，最多4^3=64种明确目标组合，单／多锚点复用有理数证书。新PL钟带首末4样本保护，构造窗口2.5帧、实际检查3帧，不可达或实际偏差失败均保留；它不保证C1/C2或艺术自然性。每条实际Core重新SO(3)采样和G1原门筛查。源感知顺序完整扫描使用同准则，与穷举选择等价，不包装为创新。

先发布代码，服务器tmux运行 `PYTHONPATH=src python -m dunhuang.research.role_alignment_q01.run preview` 并回传观看验收；之后在冻结music_events环境运行 `python -m dunhuang.research.role_alignment_q01.paired` 的6首原音频独立音乐目录，再运行 `run controls`。真实配对人口排除Q01/Q02已用身份，每域3组；它们仍有R59历史曝光，FineDance仍是genre-train/dancer-test诊断及档案同起点，不能称全新独立泛化。

正确／错位五时钟、错音乐、无类型、类型置乱、等密度、纯位置和无音乐全部报告。正偏移统一为音乐事件时间加delta，不混用音频读取符号。采用单调、不同音乐事件ID的DP与NULL匹配0，不训练参数；Top-1资格与语义资格分开。没有独立角色记录时永不准入正式路由或整曲。
