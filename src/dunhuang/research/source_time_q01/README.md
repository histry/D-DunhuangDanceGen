# Paper1-SourceTime-Q01

本轮只研究有限共同候选域的来源与执行时间可行性。冻结Q02，BAS仅诊断，SDMR、MotionCritic与新训练均不启动。旧基线生产器不改；新的决策规则独立在baselines.py，实际执行在study.py。

先推GitHub、服务器同SHA用tmux执行 `PYTHONPATH=src python -m dunhuang.research.source_time_q01.study preview`。观看并验收绑定manifest后，再运行 `study controls`，以及 `study replay` 的全新进程完整独立复验。控页由 `view.build(ROOT/'controls',CFG['methods'])` 构建。

复用三组既有非退化来源区间与48帧固定邻接，实际Core预算分别240、240、360帧。每组3个指定自动拍点目标在GTW/G1之前登记；代理动作节点是已登记低活动区间的结束，不制造为语义重音。移动支持至少2秒、目标误差≤3帧均是本轮技术约束，未根据结果设定。其他三条缺失来源机会不替换。

共同池保留Q01全部HoldDAG/Uniform时钟，并为每条来源加入一次原R53 E1-W求解器输出，使用冻结R64拍点和既有阶段格式；它是基于原算法的本轮适配，非原R52逐数组复现。E1-W只保证自身端点和合法速率，不强行声称首末4帧与Uniform相同；所有执行的G1都重新构造／测量。首末4帧完全相同的候选可按边界哈希复用同一几何构造，但每条实际上下文都重新装配和筛查，不能继承G1资格。

所有方法先获得同一预执行候选表，完整共同池成本等额记账；物理G1求解和缓存复用分别报告，不将重复缓存请求算新求解。此轮比较决策，不宣称搜索效率收益。GTW仅在同来源内排序，联合跨来源使用目标误差、实际运动支持、无量纲时钟变形。顺序失败允许检查下一来源；最强穷举顺序和联合使用完全相同准则，若结果等价就报告等价。

没有合格解时selected为空；观看页可展示明确标黄的最近诊断轨迹，但从不作为算法成功替代。原速两来源有独立入口，短来源结束后空白，不悄悄变速或循环。无世界Root、接触和Native24资格，无艺术质量或泛化结论。
