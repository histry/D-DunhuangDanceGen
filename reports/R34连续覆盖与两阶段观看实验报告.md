# R34 连续来源覆盖与两阶段观看实验报告

本轮保留单一 Lodge Local 研究主干，完成连续来源覆盖训练、三首完整音乐的 E1-W 计划重放、计划绑定的真实短窗生成及统一观看页。外围来源跟随明显改善，但原 Core 内肩腕保持未通过预登记稳定门；Context 未训练，新整曲生成0。先交付实际效果，尚未追加错时／错源／上下文消融，也不升级正式生成路径。

## 代码与训练

基准 db0d121a48f7aa212f2ddfb5e6d6e26f58a751d4；研究实现集中在 src/dunhuang/research/coverage_r34/ 与 plan_view_r34/，新脚本为 run_r34、release_r34 和只读本机观看服务。正式 EDGE、历史冻结研究与 R33 科学封存保持原样。历史研究仍被本轮调用，未为清理目录而破坏必要的复现依赖。两项实现协议见 [连续覆盖与上下文](../docs/R34连续覆盖与上下文研究协议.md)及[两阶段可视化](../docs/R34两阶段可视化与计划消费协议.md)。

WindowReference 支持变量来源长度，保留265328个参考参数；N=96沿用 R33 完全相同的计算，N=256增加实际连续来源 token，目标→来源时钟和控制 mask 显式传入。一个 Lodge 继续承担全身生成，Canonical ActionIO、General 来源分支和 Context 均冻结，没有混合 EDGE／Lodge 权重或将 Root 与身体分开生成拼接。

female_FeiTian 与 male_pipa_1 从原 NPZ 读取连续身体旋转；旧96帧 Core 的每个来源时钟原样保留，两侧按真实相邻步长延伸至256帧，实际来源范围分别约10928.93–11255.67与1548.25–1808。来源同一录制、无循环、无定格填充、无不同事件硬拼。真实 halo 支持首个速度目标；原旋转与继承 Catalog 校核通过。ChangE Root/C4 的世界／接触合同仍未知，不补成完整扩散真值。训练的肩腕与身体差分使用 Root-relative 坐标，FK 的零 Root 只是坐标规约。

Extra 与 Coverage 同起点 R33 Dyn，各600步、学习率0.0002；前者保持96帧目标，后者监督256帧连续身体。两臂复用同一日程，16条 AIST 来源各呈现75次；初始和第300步刷新均使用对应模型、对应条件的实际完整采样状态。动态尺度和 λ=0.0030652223275156342 从 R33 固定继承，没有按本轮评价调权。动态目标比较来源与输出的 D1/D2，不直接把运动压向静止。预检另执行两次有限 AdamW 更新，累计实际优化器1202步。

## 三首完整计划与实际生成联动

三首音乐分别为3601／3598／3601帧，共42／40／40个事件槽。重新求解 E1-W 候选与全局路径，并与冻结 acoustic_v1 计划逐项核对。候选来源、时间映射、合法证书、拒绝原因均保留。SDMR 全局／同步分数为身份与短名单顺序核对后的真实历史缓存，明确标为未合格 Shadow；本轮选路仍使用已登记启发式，不把它显示成文化正确率。

每首完整计划固定首个有前后邻域的内部事件，即索引1，分别以该首真实音频、独立 E1-W 映射、35D 音乐特征编译256帧研究窗口。Frozen 与 Coverage 各用两个预先固定种子34041／34042，共12条新轨迹；不是按观感挑选。三首的全局起点分别22／38／28，当前事件起点86／102／92对应各窗口局部64。

Source 仅控制当前事件，左右身体条件来自实际选中相邻事件的8帧 planned 边缘；未知 Root/C4 不伪造。Context 未训练，所以这些结果只能称“计划消费短窗压力测试”，不能认定已学习前后动作衔接。页面按实际音频 SHA、事件／来源、时间图、窗口起点、模型和噪声绑定。其他119个事件没有对应的神经生成，界面明确显示尚未生成，绝不借用旧片段冒充同一计划输出。

## 本地观看与操作

统一入口：[R34 两阶段观看页](../outputs/coverage_r34_01/viewer/index.html)。观看文件不进入 Git；本地包10文件，共45,269,291字节，包含显示 XYZ、实际音乐及页面，不含模型权重、旋转训练张量或数据集。

1. 选择 dunhuangwu2／3／4 的完整计划，在 Module I 听整曲并看来源安排、槽位、拍点、候选分数和 E1-W 曲线。计划预演保留来源切换提示，不能误认为已生成连续舞蹈。

3. 共用播放、暂停、拖动、倍速、跳帧及前后单帧；各栏显示共同整数音乐帧和局部生成帧。点击误差／Jerk 曲线定位异常。固定世界视图保留生成 Root，局部姿态视图明确 Root-relative；来源世界 Root 未知、足部接触未知。
