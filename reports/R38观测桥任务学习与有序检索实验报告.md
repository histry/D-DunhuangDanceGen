# R38：观测外端桥接任务学习与有序音乐检索

R37 保留为冻结研究基线。R38 在相同条件合同下，Context 训练使四个固定留出连续动作的平均缺口 FK RMSE 从 0.2014m 降至 0.1891m；几何桥为 0.2011m，候选相对几何桥平均下降约 5.99%。但内部 Jerk、Root 边缘加速度及跨来源物理质量仍未过关。有序 SDMR 已真实训练，顺序置乱仍取得更高检索分数。因此保持研究状态，不升级默认入口、不进行整曲生成。

## 实现与训练合同

新增代码全部在 `src/dunhuang/research/bridge_r38`；正式 EDGE、R37 科学代码、候选库、选路和来源原始数据未修改。没有引入第二个生成骨干。

1. 隐藏区为 `[104,152)`。五次 SO(3) 桥只读取 `101,102,103,152,153,154` 帧，Root 平移补间同样只使用外侧观察；缺口可以全部为 NaN。R37 原桥读入缺口两端，保留作历史基线，未将其直接改名用于训练。
2. Source 的姿态有效性和角速度有效性分开：未知导数被中和并保留显式 mask，已知姿态继续可用；没有训练新的“导数不确定性”输入通道。时间卷积按可见连续事件分别执行，隐藏区不进入局部 memory、全局 token 或 Context。事件边缘不再求跨来源导数。
3. 只更新已有 268,160 参数 Context；Lodge、CanonicalIO、General 和 Source 权重冻结。16条既有 AIST 配对训练录制，固定240步，AdamW lr=1e-4。四个本轮留出案例为4/8/12/16，不参与这些更新；这些资产已有历史研究曝光，不能称为新的独立盲测。
4. 从几何底座开始，t=119、50次反向更新、种子35041/35042，Source 残差使用相同 C2 门控，身体按同一0.6rad包络逐步投影。训练缓存来自初始冻结桥的实际采样状态，并混入几何底座加噪；没有给待补真值加噪作为初始状态。缓存未随训练刷新，因此不是完全 on-policy 训练。训练用条件分支，采样沿用 CFG，不能称为所有训练／采样状态已经完全一致。
5. 几何／D1／D2 目标来自真实连续录制，尺度只由 Train 几何误差校准。Root 仅在配对数据上监督；本轮未训练 FineDance 或 ChangE。异源硬切从未作为连续真值。未使用伪造 ChangE 音乐、Root 或接触标签。
6. 外侧主体由复制／投影保护，不归为网络学习到的文化或风格保真；C4 是模型特征，不是已验证静态支撑真值。语义阶段仍 UNKNOWN。

## SDMR：独立有序编码研究

复用 R37 已核验的4632 Train／648 Val可变长度配对窗口和 Train-only Normalizer。音乐加入两层 TCN、位置编码与注意力池化，动作 Transformer 加位置条件，保留 token 重建；内容输入屏蔽原动作特征中的显式时间进度和时长两通道。全局兼容对比之外加入物理来源时钟的 token 对应辅助损失；它不是语义重音—发力真值。

固定80更新、每批8行：两首音乐，每首两个不相交时间段，每段两个不同可信录制。242个精确时钟候选组、48个Train音频身份可供采样；每条训练查询实际至少两个正例，不再只是接口支持多正例。模型337,544参数；本轮是一个结构／数据关系联合主候选，没有新做打乱训练、去模块等消融，不能因结果差异单独归因于TCN。

| 诊断 | 全候选R@1，648查询 | 同音乐时段R@1，296查询 | 同长度／近特征强度R@1，508查询 |
|---|---:|---:|---:|
| 原顺序 | 9.26% | 53.38% | 25.59% |
| 音乐帧顺序打乱 | 10.80% | 57.43% | 27.76% |
| 非循环+15帧移位，尾部无效 | 6.17% | 60.14% | 25.59% |

近强度使用 Train 校准的音乐特征 RMS 与动作角速度 RMS 各自标准化，差值<=1，且长度相同；它是特征强度代理，不是校准声学能量或艺术匹配。覆盖508/648，未放宽池子来补齐查询。全候选／同音乐／受限池的均匀随机候选期望分别约3.47%／45.50%／10.53%，不是强时间或能量基线，不能仅超随机就宣称取得资格。

R37历史全候选R@1约20.06%，本轮更低；时段分数提高也不能抵消置乱更高的失败证据。任务池、学习结构和训练关系应一并阅读；没有内容排序资格、跨域敦煌艺术正确率或因果模块归因。六组曝光Val的分组结果全部保存在 JSON 中，`can_route=false`。

## 规划与原始资产审查

三首音乐继续展示原R37整曲计划，未重新切短或强迫换源。增加来源占时、最长连续来源、相等时间三段描述、声学乐句候选、低速帧比例与不同原始区间之间的SO(3)近似度。保持／发展／主题再现均未强行标成语义真值。

最长连续同来源时长：song0 33.73秒，song1 36.83秒，song2 32.10秒。song1 两条 meditation 来源合计约83.77秒；同来源持续发展不等于机械循环。页面直接显示来源占时，详细轨迹相似对照保存在 `planning_diagnostics.json`，本轮未据Val效果修改选路。

本机对 `danceRAG/assets/motion/smpl_official_14/sources.json` 登记的八条单轨来源核验了原文件 SHA。原始55关节格式确实含有限、非零世界平移数据；22之后的手／面部轴角全部为零。故“没有任何原始Root资产”不成立，但恢复世界参考仍需源SMPL-X形状、J0、坐标和地面合同，不能直接把现有身体-only参考改称世界真值。缺失末端旋转无法从零占位恢复，Native24保持 NOT_EVALUABLE，不额外补零制造合格。

## 方法参考与结论边界

借鉴 [CondMDI，SIGGRAPH 2024](https://setarehc.github.io/CondMDI/) 的已知观察与缺失区分、补间任务训练思想；本研究仍是音乐条件Lodge与有界编辑，不称完整复现CondMDI。保留 [TMR，ICCV 2023](https://mathis.petrovich.fr/tmr/) 所强调的检索与重建联合约束，但没有将文本任务论文的效果直接移植成音乐动作结论。

本轮可支持“匹配桥任务的Context学习带来部分真实目标构形收益”和“已修复音乐顺序表征的结构性缺口”；仍不能支持“神经过渡优于强几何底座的综合质量”“Root与足部稳定”“音乐时序与敦煌内容匹配已取得资格”。先观看并保留这些原始差异，后续只在明确机制问题上做最小对照。
