# R64 音乐代理与固定预算时间分配实验报告

## 结论

本轮完成共同候选图上的局部时间分配、真实动作观看交付和音乐奖励干预。音乐奖励确实改变部分来源时钟与动作轨迹，但未取得相对 Fixed48 的稳定动态净收益。保留 Fixed48 强基线，不升级整曲联合 Planner，不启动新的 SDMR／Diffusion 训练。

这里执行的是普通拍点、声学重音及结构代理的局部评分诊断。没有独立小节强拍和乐句标注，真正的三尺度协同规划仍为 NOT_EVALUABLE。本轮没有把 R63 已曝光人口重新命名为独立盲测。

## 代码修正的证据

R36 历史音乐代码将工程首尾 `[0, frames]` 注入拍点列表。末端 `frames` 不是真实音频帧中心，初次 R64 严格预检因此失败。修正仅从新 MusicClock 的奖励和 Tempo 中排除有明确代码证据的两个人工哨兵，原始列表、排除原因、算法 SHA 和实际音频样本数均保留。

三首音乐的旧列表为 175／221／241 点，保留内部候选后为 173／219／239 点。原 `case.beats`、E1-W 和冻结父实验均未改变。其他重复、非递增或越界时刻继续拒绝。历史文件没有保存内部点究竟来自检测器还是规则回退的逐次分支，故不能把保留点称为独立核验节拍真值。

## 同图、同预算评分

LocalBalanced 的成本为 Core 合法时间图变形与 Bridge D2／D3 归一化成本的等权组合。LocalBeat 在此之上减去 `0.5×beat/accent 均值 + 0.1×section 代理`；BeatOnly 在同一 Balanced 成本上仅增加普通拍点奖励。权重、并列规则和人口均在执行前冻结。

ShuffledBeat 仅将新增音乐奖励证据按整首音乐半周循环移位；真实音频、E1-W 拍点、来源和几何图不变。循环移位可能保留节拍周期，不能假定音乐信息已经完全被破坏。真实强拍和独立乐句政策保持 NOT_EVALUABLE，没有伪造其效果。

原 G1 门是共同筛查。另行记录 Core 路径／幅度至少为自身 Fixed48 的 0.9 倍、全段 D3 Q95 不超过其 1.05 倍的相对保持诊断；该诊断不用于过滤或选路。Fixed48 与自身比较自然通过，不是独立质量资格。

## 结果

725 个候选均可构造；原 G1 门通过数为 DEV 204/225、EVAL 500/500。不能将可构造写成全部数值合格。

EVAL 各政策选中 20/20 且通过原门。下表 D3 为逐例整段 Root-relative 身体 FK 的 D3 Q95，再对 20 例取均值，单位 m/s³；不是 Native 世界 Jerk，也不是对视觉自然性的判决。

| 政策 | 原门通过 | 额外相对保持诊断 | 整段 D3 Q95 均值 | 正确时钟音乐代理均值 |
|---|---:|---:|---:|---:|
| Fixed48 | 20/20 | 20/20（自身参照） | 160.023 | 0.485252 |
| Fixed24 | 20/20 | 16/20 | 152.156 | 0.462597 |
| LocalShortest（零偏移） | 20/20 | 16/20 | 152.156 | 0.462597 |
| BalancedEqual | 20/20 | 12/20 | 162.769 | 0.472822 |
| LocalBalanced | 20/20 | 14/20 | 158.284 | 0.473485 |
| BeatOnly | 20/20 | 15/20 | 155.628 | 0.524808 |
| LocalBeat | 20/20 | 12/20 | 161.229 | 0.513721 |
| ShuffledBeat | 20/20 | 18/20 | 150.594 | 0.485218 |

LocalBeat 相对 Fixed48 的音乐代理分数升高，但这正是其优化目标，不能作为独立音乐协调证据。全段 D3 均值略升，保持诊断从自身参照的 20/20 变为 12/20；这些入选方案的诊断失败均来自全段 D3 超过 1.05 倍，没有 Core 路径／幅度不足。较大的 D3 本身仍可能包含真实快速动作，不能直接称为抖动或艺术质量失败。

LocalBeat 与 ShuffledBeat 的选择及完整轨迹哈希变化为 DEV 3/9、EVAL 11/20，共 14/29。LocalBeat 相对 LocalBalanced 改变 DEV 4/9、EVAL 9/20。因此新增奖励确实影响决策，但正确奖励没有建立稳定质量优势；置乱组的动态数值反而更低。不能从这些数据声称音乐层次规划成功。

DEV Fixed24 的相对诊断 9/9 也不能掩盖原门只有 7/9，联合通过仍为 7/9。完整逐例记录保留失败和条件均值分母，不跨版本直接套用 R63 的政策统计。

## 后续决定

不在这 20 条已曝光边上调整权重以挑选更优结果。当前证据支持“音乐奖励能改变局部时间选择”，不支持“自适应时间优于固定48”或“音乐三尺度提高质量”。继续保留 Fixed48；若要推进，应先取得未用于本轮设计的音乐结构记录和评价人口，预登记质量评价与帧预算，再验证真实拍点／重音贡献。此轮不扩大来源选路、不训练新模型、不运行整曲规划。
