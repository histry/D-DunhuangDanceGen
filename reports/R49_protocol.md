# R49 事件级音乐对齐

冻结基线为 `540bb27`。试验代码在独立研究入口。先交付三首历史敦煌音乐的代表槽位播放，再运行消融与 Val。展示内容是来源动作的合法重定时。

- P1 扫描 R48 所有 4,177 个已登记时钟变体。每个事件在每个目标时段恰有一次候选预算。先校验来源、完整时钟、局部窗口一致性和真实观测。评分为 R41 96D 局部逐帧余弦均值，加 0.1 倍 1/4/12 帧能量和身体速度相关，减 0.05 倍时钟绝对对数斜率。权重在结果前登记。预演槽位按曲目时间中点选取，动作以相同音乐、尺度和相机比较。活动度臂是在同一 R48 库重算的启发式代理，正式 Planner 另作冻结基线。
- P0 测原 R41 Val，从整段录制构造运动特征。冻结音频、归一化、权重和真实时钟。相位评分比较零偏移与 ±8/±15，所有分数共用实际支持，同录制先平均再按音乐聚类。事件排序的正例是同录制核验时钟，四个负例来自其他录制。固定 90 帧，分别考察同音乐错时和近运动能量候选。后者使用离线目标运动统计构造困难池。来源分组按音乐作品、音频、录制及原始动作身份核验。历史 Val 已曝光。真正独立测试需要经登记并核验历史曝光的新来源。
- 消融的线性和多锚点时间图共享事件、目标帧数及合法速率范围。所有实际使用的掩码记录在结果中。科研预演结果不能作为目标域艺术偏好真值。
- 研究继续保持 Shadow。阶段监督需独立可核验对应，Root 和足部任务需完整观测。P2–P4 按资格用途运行，绝不从非配对 ChangE 输入构造跨音乐姿态真值。
