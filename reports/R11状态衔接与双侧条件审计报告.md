## 3. 实际接缝：Root、朝向与局部姿态都在变化

读取original/zero/C1/C2在59、60、65、89、90帧的世界Root、局部SO(3)、髋/膝/踝、四足端、9帧足迹和向后D1/D2/D3。帧索引从0开始；截图“第65帧”对应64，检查器并列显示两种编号。

下表按8案例、每例两个接缝等权平均；16个接缝不是16个独立来源。

| 保存动作 | Root单步位移 m | Root转角 rad | 四足端单步位移均值 m |
| --- | ---: | ---: | ---: |
| 原动作 | 0.011080 | 0.041715 | 0.022275 |
| ZERO | 0.378635 | 0.279461 | 0.409484 |
| C1 | 0.334409 | 0.270234 | 0.364963 |
| C2 | 0.307247 | 0.257217 | 0.343183 |

C2相对ZERO略小，仍远离原运动状态。对足端变化作Root平移、Root旋转、局部姿态的对称代数分解，恒等式核验通过；这些signed分量会抵消，不是“因果贡献百分比”。不能仅看截图就认定只有腿部姿态出错或只有Root坐标出错。

用户指出的1_temporal_A中，C2左接缝Root跳变0.237791m，原动作0.014008m；右接缝0.791736m，原动作0.010703m。四足端同样出现明显步长变化，完整逐帧数据保留在audit/result.json。

## 4. 跃变首次出现在哪里：原始预测 → 硬覆盖 → 坐标/回接

逐例读取冻结最后一步x0与原产物。验证：

1. 未观测中间区与原始x0逐位一致。
2. 只用真实硬Mask覆盖已知元素，就能逐张量重建最终normalized窗口。
3. 反归一化、单窗装配、Native坐标转换、恢复原点及回接各自的Root数值差异不超过提前登记5e-6m。

| 最后一步阶段 | 接缝Root单步位移均值 m |
| --- | ---: |
| 原动作 | 0.011080 |
| 原始模型x0预测内部 | 0.024393 |
| 硬覆盖已知状态后 | 0.307247 |
| 反归一化后 | 0.307247 |
| 单窗装配后 | 0.307247 |
| Native/原点恢复后 | 0.307247 |
| 最终graft回接后 | 0.307247 |

原始模型在已知接缝状态的Root误差均值为0.298634m、Root转角误差0.214653rad。其内部运动相对平缓，却没有到达真实边界；强制将已知帧改回真实值后，未知帧保持原预测，于是接缝突变。四足端步长均值也从原始x0的0.033231m变为覆盖后的0.343183m，graft后仍0.343183m。

这定位了本轮最后一步算子的数值变化，不是独立Hard-Off完整轨迹因果实验。不能据此删除正确硬约束：那会失去真实上下文，也没有物理/来源资格。真正待解决的是去噪器在强制覆盖前就应输出边界兼容的动作状态。

## 5. 左右条件拆分：修正诊断接口，不宣称训练新Bridge

冻结C2原接口要求第59帧Root可见，直接移除左侧会拒绝输入。本轮将坐标标尺与软观察拆开：

- 所有条件共用真实硬上下文59帧水平Root作公共坐标标尺。
- A2的左侧内容、Mask、速度/加速度全部移除，标尺不作为额外软观测；隐藏值隔离测试通过。
- A0在400个实际去噪状态的特征逐张量与原C2相同，完整采样六类数组与原C2一致。
- 错配只改变指定一侧；原硬Mask、音乐、x_t和RNG不变。单侧移除和公共坐标替换可能超出原训练分布，不能据此宣称已具单侧生成资格。

A0正确双侧；A1移除右；A2移除左；A3错配右；A4错配左；A5两侧移除。每个A0轨迹状态上计算6种前向预测，只有A0驱动真实采样。其余5种不是各自完整rollout，也没有各自产生新的完整动作或Native通过结论。

A5残差精确为零仅是结构性质。硬路径始终正确，所以软增量弱不能证明整个EDGE完全不读取硬上下文。

## 7. 训练机制的具体边界

当前采样器每步重新绘制噪声，对下一步已知区作覆盖；不是用同一噪声跨越所有t。真实完整q(x,t)上若再用相同真值、相同噪声替换已知Mask，会严格等于原x_t，已用测试验证。不能把这条恒等操作包装成新的Mask-Aware训练。

[CondMDI官方训练循环](https://github.com/setarehc/diffusion-motion-inbetweening/blob/main/train/training_loop.py)明确传入obs_x0/obs_mask。这值得借鉴，但本轮没有复现其模型，也不声称已实现BADM或FlowMDM的网络。

下一阶段应先在训练人口验证运动状态条件到Root/姿态的可辨识通路，单列强制覆盖前的已知状态误差与两端运动状态，再登记新的监督和预算。原R10损失主要作用于未知区和与真值已知帧混合后的边界；强制后的Anchor误差为零不能替代原始预测的边界兼容性。这是新的待验证机制，不能靠继续同接口延长训练或取消硬边界宣称解决。
