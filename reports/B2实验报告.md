# B2 连续敦煌姿态引导实验

同一首曲目、同一随机种子、同一冻结 EDGE，在 5 秒、15 秒、3601 帧整曲上各运行三个条件。每个时长内，三组初始噪声和全部反向步骤噪声的 SHA256 一致，窗口使用同一均值共识。三次硬锚点重放的 Native 动作 SHA256 均与上一轮相同。九组完整 Native 均未通过。

时间引导以三个原锚点为中心，取各自真实来源前后 12 帧，按 30 FPS 一比一映射。每帧八个关节均经过冻结 normalizer 范围与往返检查。源旋转与去噪预测在 SO(3) 上插值，时间权重为余弦平方，峰值强度 0.55，随反向步进按进度平方增长。源轨迹提供连续参考，本次没有显式速度或加速度损失项。引导产生的越界候选关节保留该步模型预测。

整曲中，渐进组在三个中心的平均角误差为 0.106 rad，连续源轨迹误差降到 0.306 rad，锚点附近最大单帧位移比硬锚点低约 92%。整曲最大 jerk 位于第 3451 帧右手末端，无锚点组也在同一帧同一关节出现峰值。该帧紧邻重叠窗边界，当前比较不足以确定峰值的成因。所有帧号从 0 起计。角误差取相对旋转的旋转向量模，接近零时与首轮使用的 arccos 读数存在浮点差异。

5 秒通过全部六项方向性检查。15 秒及整曲都改善了姿态与位移，但滑足 P95 分别从硬锚点的 0.414、0.8999 升至 0.438、0.9007 m/s，均高于 Native 的 0.18 m/s 阈值。原实验入口在 15 秒停止，整曲随后依据方案的 5 秒扩展条件单独续跑，沿用完全相同的参数。15 秒与整曲相对于硬锚点的滑足比较均记为失败。全套 Native 限值、失败原因与原始数值见机器报告。单曲单种子的结果无法估计跨音乐成功率。

## 保存结果的责任定位

首轮硬锚点投影前最后一步最大归一化残差依次为 0.83735、0.82948、0.73590。5 秒硬锚点在第 77 帧达到峰值，距第 75 帧目标两帧；该样本只有一个窗口。整曲纯 EDGE 的最大重叠差在归一化空间为 0.59713，反归一化后为 0.44566。硬锚点两项均为零，整曲仍有显著 jerk。旧整曲纯 EDGE 的 Native 静态支撑帧数按四个足部关节计为 17、10、2671、2294；不同足可同时支撑。逐区间的起止帧及速度分布在 saved_diagnostics.json 中。

## 完整上肢和音乐条件的独立试验

八个来源共覆盖 41,400 个 catalog 帧，单帧十关节全部在支持域内的有 2,055 个。允许在同一事件中取满 25 帧的 29,424 个中心里，仅 106 个满足整段十关节支持，其中 93 个来自男子飘带、12 个来自女子飞天、1 个来自女子莲花。106 是允许重叠的中心位置数。

独立 5 秒检索使用已绑定音乐槽的目标动作密度、源上肢活动度百分位和前后片段的旋转距离。三个节拍均选中同一男子飘带事件，原始中心帧为 114、113、113。十关节轨迹通过逐帧预检并完成采样，中心平均误差约 0.166 rad，Native 未通过。该选择结果暴露了候选集中和重复问题。当前尚缺独立风格、音乐语义和人工自然性评价。

## 纯 EDGE 的独立支撑修正

在旧官方 EDGE 整曲上，用连续两帧均为 Native 静态支撑的 4837 个足部步长拟合一次水平根位移。平滑最小二乘同时惩罚位移和二阶差分，最大位移限定为 0.06 m。只修改 Root XZ，重新运行 FP32 FK 和完整 Native。滑足 P95 从 1.052 降为 0.947 m/s，最大 jerk 从 24111 降为 23876 m/s³；完整审核仍失败。该实验未纳入八关节 A/B/C 的任何生成结果。
