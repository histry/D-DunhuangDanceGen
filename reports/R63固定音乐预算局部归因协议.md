# R63 固定音乐预算的 Core–Transition 局部归因协议

基线为 `857d1f4`。本轮不改变正式生成器、SDMR、Planner、原 G0/G1 及其数值阈值。

每个局部任务的音乐时间固定为 528 帧。过渡采用 24/36/48/60/72 帧，对应两个 Core 分别采用 252/246/240/234/228 帧。来源事件、完整来源区间和顺序不变；每次重新运行冻结 E1-W、重采样完整 Core、计算实际边界导数并运行冻结连接。不可执行的 Warp 或图域保留失败，不替换来源、不裁短、不回退。

R62 的九条连接为 DEV，涉及三条已曝光来源。评价采用剩余五条 ChangE 来源，每条按离240帧最近、再按来源时间顺序选择一个 R47 单元，保留全部20个有向异来源对。它们只相对本轮规则拟合来源隔离，不能称为完全未见来源；三首音乐也是历史开发音乐。20条边共享五条来源，报告有限人口和来源参与次数，不以边为独立样本计算置信区间。

先交付 Fixed48 与 ShortestScreened 主效果。ShortestScreened 从短到长调用新编译 G1 与原数值门，遇首个通过即停止；它是筛查搜索而非学习预测。BoundaryConditioned 为 DEV-only 标准化 1NN，读取固定48帧方案的两端真实四帧姿态、角速度与角加速度，使用 DEV 新固定预算筛查标签；模型和评价预测在求解评价替代长度前封存。预测不合格即拒绝。规则拟合一次，不进行优化器或神经训练。

完成主观看验收并绑定结果SHA后，才执行 Fixed24、BoundaryConditioned 与固定48帧 G0 强基线对照。所有方法共享完整528帧音乐、来源和原几何筛查，报告整段/Core/Bridge/接缝、活动幅度与节拍代理，保留全部失败分母和实际筛查次数。另登记保守诊断：两侧 Core FK路径和范围相对Fixed48均至少0.9，整段D3 Q95不超过Fixed48的1.05倍；该诊断与原门分开，不能取代自然性或Native。

此次变化同时改变 Core 动态和边界状态，是局部联合时间分配效应，不能解释为孤立的过渡长度因果效应。若仅追平Fixed24或标签退化为常量，不认定自适应价值。即使局部数值通过，本轮不启动整曲搜索；专业语义、Root、接触及Native24仍未取得资格。
