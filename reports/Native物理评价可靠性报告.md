# Native 物理评价可靠性审计与 Shadow 标定

本轮保留 Native-Legacy-v1 的31项限制、接触算法、完整判决和默认生成路径，新增连续观测、独立接触证据接口、地面/骨架合同和 Native-Calib-v2 研究接口。Native 是运动学与接触合理性审核，不是接触力、摩擦锥或动力学平衡的可执行性证明。

实验代码：2118baab6ef1a6aabf9d7847d60fb651610e91d9，先发布 GitHub，再同步服务器，以独立 tmux 会话 ddg_native_calibration_03 执行。报告与机器汇总是随后提交的证据整理，不代表另一次训练或采样。服务器直拉 GitHub HTTPS 超时后，使用已核对 GitHub main 的 Git bundle，校验 SHA256、验证 bundle 并 fast-forward 到同一提交；没有关闭 TLS 校验。

## 工程与算法改动

- 数值完整性层：FP32/151D/30 FPS、有限值、Rot6D非退化、骨架/地面身份及原官方 FK 的1e-5 m复核。
- 连续观测层：保留完整旧指标；分别报告推导接触D、低足高H、交集/并集与原 Contact4，给出人口、覆盖率、足速/漂移、Jerk分布/违规率/持续时间、PFC、Root与活动度。无可评价接触报告 NOT_EVALUABLE 和 null。
- 判决层：旧 physical.json 数值与结构不变，新增 physical_protocol.json 和 native_layers.json。Shadow不替代旧结果，不能驱动 replanner。
- 来源与标定：31项限制逐项登记单位、计算人口、聚合、A/B/C类别和工程来源。Root的10秒位移与Jerk等1秒P95窗口统计明确区分。上限/下限分别描述Q95/Q05，统计分位不是自动门限。
- 独立标注接口：接触标注绑定动作SHA、帧数/时钟、足关节、标注人和独立来源；质量标注另绑审查协议SHA。可选候选引擎只使用独立质量/接触证据，并按来源组统计误拒/漏检及整组bootstrap；即使输入完整标注，也只产生Shadow提案。
- 发布接口：公开导出器只输出汇总与哈希；逐窗来源、原视频、模型资产和机器路径保留在忽略目录。

见[复现与标注接口](../docs/native_calibration_v2.md)、[固定设计](../configs/native_calibration_v2.json)和[机器汇总](native_reliability_summary.json)。

## N1：训练目标与接触责任

1,468个已准入跨录制Train目标来自708个录制、60个官方编舞身份、6个已知关联来源组。旧Native仍为40/1468 PASS；足滑P95超限1,423窗、足滑Max超限1,355窗、支撑漂移P95超限1,303窗、Jerk Max超限1,045窗。一窗可违反多项，不能相加。

旧并集支撑人口中，速度超过0.18 m/s的重叠窗口—帧—足观测共163,764个：

| 归属 | 数量 | 占这些超限观测 |
| --- | ---: | ---: |
| 仅推导接触D | 0 | 0% |
| 仅低足高H | 141,246 | 86.25% |
| D、H同时命中 | 22,518 | 13.75% |

另存的录制均衡描述量为82.493%：每窗H-only/超限观测的比例，无超限窗记0，再在录制内和录制间分别平均。它与上表按观测计数的比值是不同估计对象。

这些观测重叠，不能视为独立帧样本；H-only也不能解释成合法滑步或误拒。低足高分支确实纳入大量速度观测，但多少属于拟合误差、真实静态足滑或有意滑步，仍需独立审查。

在本轮检查的资产登记和相关文件名范围内，尚未获得经独立审查的真实接触/质量标注。新真实静态足速与漂移保持UNKNOWN/NOT_EVALUABLE，不从同一速度阈值反推静态标签，也不因高足速授予合法滑步。固定每组两个录制、共12窗的待标注包绑定视频SHA、时钟/对齐回执和动作SHA，全部状态初始为-1、validated=false。

## N2：地面、骨架、长度与噪声

同一保存动作分别用冻结公共网格地面、冻结公共Native关节地面、候选自身Native地面评价。三者均为几何代理，均非实测场景地面。neutral beta0网格与Native固定偏移骨架分别标识，不将足关节最低高度冒充网格穿透。

42次执行中，neutral beta0与Native全部24关节的逐例最大差范围约4.457–5.184 cm，足关节对应范围约3.766–4.222 cm；neutral网格/关节与smplx==0.1.28参考的最大误差均为2.384e-7 m，小于1e-5 m。前者是骨架定义差异，后者是网格实现数值一致性，不能混淆。

同一组12次AIST Cross执行，在不同地面协议下的网格指标中位数如下，单位mm：

| 地面协议 | Penetrate | Float |
| --- | ---: | ---: |
| 冻结公共网格地面 | 1.628 | 52.911 |
| 冻结公共Native关节地面 | 8.516 | 37.012 |
| 候选自估Native地面 | 3.882 | 29.004 |

表中只改变评价地面，未改动作，不能据此选择最有利地面或宣布某种生成结构质量更好。

预先固定23个合成中性姿态测试：静态滑移与显式合成滑步各4档、穿地/浮空各4档、RootY抖动5档，以及无静态接触、未知高速各一例。静态滑移、网格穿地、网格浮空和原始Jerk对应曲线均单调。它们是算子响应测试，不是经专家确认的高质量真实舞蹈异常检测。

协议边界十分明确：静止合成动作整体下移/上移10/30/60 mm，候选自估地面同向移动，Legacy穿地最小值均为0且均PASS；固定合成平面的网格深度则约为10/30/60 mm。另一个上移300 mm、无静态标签的合成腾空例，Legacy仍PASS，而固定平面Float约300 mm，静态足滑为N/A。这证明自估地面不能区分全局竖直平移；不证明公共代理地面就是真地面，也不证明真实腾空都不合理。

固定12段原始录制均支持150帧、10段支持300帧、0段支持450帧；14个不足长度组合明确跳过，未补帧、拼接或循环。另对两条保存的3,601帧生成动作分析150/450/900/1800/3601帧前缀。两类人口不能混为真实源动作的长程结论。

Jerk使用未改写的30 Hz原始FK三阶差分；补充Gaussian低通只作诊断，不覆盖动作或改变Legacy。原始源的固定0/0.5/1/3 mm、10 Hz RootY噪声及完整长度/违规率见机器汇总。没有根据结果改选噪声幅度、门限或权重。

## N3/N4：尚未满足的科学资格

历史Train的6个已知连通来源组按哈希预分4组标定、2组保留，共972/496窗，没有共享已知录制、编舞和音乐身份。分别按录制、编舞与来源组bootstrap300次。仅4个标定来源组，不能宣称区间覆盖率或统计独立性已成立；历史Train再划分也不是新盲测。

缺少独立高质量真值与真实静态/滑步标注，因此候选正式门限、真实误拒率/漏检率、专家一致性全部为null。真实目标Legacy失败率不能称为误拒率；参考分布Q95/Q05不能直接覆盖31项旧限制；合成曲线不能称为真实异常检出率。未放宽门限、删除失败目标或重选checkpoint。

N0/N1/N2的工程、只读实验及独立重放已完成；N3独立真值标定和N4专家一致性仍未合格。Native-Calib-v2保持SHADOW_UNQUALIFIED，operational_qualified=false，can_route=false。默认生成与验收仍沿用旧Native。

## 公开指标与边界

[EDGE论文](https://openaccess.thecvf.com/content/CVPR2023/papers/Tseng_EDGE_Editable_Dance_Generation_From_Music_CVPR_2023_paper.pdf)及[固定版本PFC源码](https://github.com/Stanford-TML/EDGE/blob/17c3428669ed6733edd9d8c66f7dc62060b8e46d/eval/eval_pfc.py)支持舞蹈足部运动需要按编舞解释。这里保留既有PFC定义和零Root加速度的未定义状态。

[PhysDiff附录](https://arxiv.org/html/2212.02500v3#A1)给出网格穿地/浮空与接触位移指标。这里沿用已声明的附录重实现，保留5 mm dead-zone/full-depth容差解释、50 mm几何接触规则及其人口，不宣称作者代码同一性或排行榜可比。几何接触也不是独立静态真值。

本轮训练步数、优化调用、新生成次数均为0；未重新提取已有Jukebox。后续有效进展依赖独立审查拟合动作与视频接触、校准场景地面，以及分开评价活动度/自然性。
